## ทดสอบ PIR → กล้อง → ไฟส้ม กับของจริง

1. เปิดหน้าเว็บ เอาเครื่องหมายออกจาก "ตรวจอัตโนมัติ" (จะได้รู้ว่าภาพที่ถ่ายมาจาก PIR จริง)
2. รอช่อง **PIR** บนหน้าเว็บเลิกขึ้น "อุ่นเครื่อง" (ปกติ 10–20 วินาทีหลังบอร์ดบูต)
3. ถือภาพนกไว้หน้ากล้อง แล้วโบกมือผ่าน PIR
4. ข้อความใต้ภาพต้องขึ้น **"PIR ทริก → พบนก 1 ตัว"** และไฟส้มติด (ช่อง "ไฟส้ม (เจอนก)" = ติด)
5. เอานกออก รอ 5 วินาที ไฟส้มต้องดับเอง
6. ปุ่ม **💡 ทดสอบไฟส้ม** ใช้เช็กสายรีเลย์ช่อง 3 ได้โดยไม่ต้องรอเจอนก

PIR ทริกซ้ำได้ทุก 5 วินาที (`PIR_LOCKOUT_MS`) ถ้า OUT ยัง HIGH ค้าง (นกยังอยู่) จะทริกซ้ำทุก 5 วินาที
หน้าเว็บนับแยกเป็น **ทริกใหม่** กับ **ทริกซ้ำ (OUT ค้าง)**

**กันค้าง:** ถ้า OUT ค้าง HIGH เกิน 30 วินาที (`PIR_STUCK_MS`) และกล้องไม่เจอนกเลยใน 30 วินาทีนั้น
บอร์ดจะเลิกสั่งถ่ายซ้ำ หน้าเว็บขึ้นเตือนสีเหลือง "PIR ค้าง" ถ้ากล้องกลับมาเจอนก (จากรอบตรวจอัตโนมัติ)
หรือ OUT กลับเป็น LOW จะกลับมาทำงานปกติเอง

## PIR หลอน: ตั้งค่าและหาสาเหตุ

**ตั้งค่าบนตัว HC-SR501**
- จัมเปอร์ trigger: ฝั่ง **H** (ทริกซ้ำได้ระหว่างที่ยังมีการเคลื่อนไหว)
- ปุ่ม **Tx** (หน่วงเวลา): ทวนเข็มจนสุด (~3 วินาที) ถ้าหมุนไว้มาก OUT จะค้าง HIGH เป็นนาที
- ปุ่ม **Sx** (ความไว/ระยะ): เริ่มที่กลาง ถ้ายังหลอนให้ลดลง

**อ่านการ์ด "บันทึก PIR" บนหน้าเว็บ**
| เห็นอะไร | น่าจะเป็น | แก้ |
|---|---|---|
| "กระตุก" เพิ่มเรื่อย ๆ | สัญญาณรบกวนเข้าสาย / ไฟเลี้ยงไม่นิ่ง | เลี้ยง PIR ด้วย 5V, ใส่ C 100µF + 0.1µF คร่อม VCC-GND ที่ตัว PIR, สายสั้น ตีเกลียวกับ GND, แยกจากสายมอเตอร์ |
| "ทริก" ทั้งที่ไม่มีอะไรขยับ, HIGH ~3 วิ | เซนเซอร์เห็นความร้อนเปลี่ยนจริง | หันออกจากลมร้อนคอมเพรสเซอร์แอร์ แดด หรือใบไม้ไหว / ลด Sx / บังเลนส์บางส่วน |
| ทริกตอนกดปั๊ม/ไฟ | รีเลย์ดูดไฟจาก 5V ร่วมกับ PIR | ให้ PIR ใช้ 5V คนละเส้นกับรีเลย์ หรือใส่ C ที่ PIR |
| HIGH ค้างนาน 20+ วิ | ปุ่ม Tx หมุนไว้มาก | หมุน Tx ทวนเข็มจนสุด |
| "ทริกซ้ำ" วิ่งขึ้นเรื่อย ๆ / เตือน "PIR ค้าง" | Sx ไวเกิน เห็นลมร้อน/แดดเป็นการเคลื่อนไหวต่อเนื่อง | ลด Sx (ทวนเข็ม) ทีละนิด แล้วลองเดินผ่านว่ายังจับได้ไกลพอ |
| "ไม่สนใจ (มอเตอร์หมุน)" เพิ่ม | ปกติ: ตัดการทริกตอนหัวฉีดหมุนและ 2 วิหลังหยุด | — |

## สิ่งที่ต้องทำหลังอัปเดต

1. **ตั้งจุดกลางมอเตอร์ทุกครั้งที่เปิดเครื่อง** — หมุนหัวฉีดให้อยู่ตรงกลาง แล้วกด
   "⌖ ตั้งตรงนี้เป็นจุดกลาง" บนหน้าเว็บ (ถ้ายังไม่ได้ตั้ง หน้าเว็บจะเตือนสีเหลือง)
2. **ตั้งรหัสผ่านหน้าเว็บทันที** — เปิดเว็บครั้งแรกจะเจอหน้า "ตั้งรหัสผ่าน" (ใครเปิดก่อนได้ตั้ง)
   ดูหัวข้อ "รหัสผ่านหน้าเว็บ" ด้านล่าง
3. **ROI เปิดอยู่ตั้งแต่เริ่ม** (ตัดขอบซ้าย-ขวาออก 20% เหลือตรงกลาง) — ปรับด้วยแถบเลื่อน
   บนหน้าเว็บให้กรอบแคบรอบจุดที่นกชอบเกาะ ระบบจะตัดภาพเฉพาะกรอบก่อนตรวจ
   ทำให้เจอนกตัวเล็กได้ดีขึ้นมาก กด "ค่าเริ่มต้น" เพื่อกลับไปค่าตั้งต้น
4. ค่าเริ่มต้นเป็นเวอร์ชัน `normal` (ไล่จริง) ถ้าจะเก็บภาพไปเทรนก่อน ให้เปลี่ยนเป็น `train` ตามหัวข้อด้านบน

## รหัสผ่านหน้าเว็บ (v7.0)

- ทุกหน้าต้องล็อกอิน รวมภาพสด ภาพย้อนหลัง log และไฟล์เทรน / จำการล็อกอิน 30 วัน / มีปุ่ม "ออกจากระบบ" มุมขวาบน
- ใส่ผิด 5 ครั้งติดกัน ล็อก 5 นาที
- **เปลี่ยนรหัส:** หน้าเว็บ → "รายละเอียดเชิงเทคนิค" → "เปลี่ยนรหัสผ่านหน้าเว็บ" (เครื่องอื่นที่ล็อกอินไว้จะต้องล็อกอินใหม่)
- **ลืมรหัส:** บน Pi (SSH หรือต่อจอ) สั่ง `python3 ~/bird/raspberry_pi_server.py --set-password` ใช้ได้ทันทีไม่ต้องรีสตาร์ท
- รหัสเก็บเป็น hash ใน `~/bird_images/auth.json` (ไม่เก็บตัวรหัสจริง) ลบไฟล์นี้ = กลับไปหน้าตั้งรหัสครั้งแรก (ถ้าไม่ได้ตั้ง `BIRD_PIN`/`BIRD_PASSWORD` ไว้ใน service)
- `BIRD_PIN` ของรุ่นเก่ายังใช้ได้เป็นรหัสเริ่มต้นตอนยังไม่มี `auth.json` (หรือตั้ง `BIRD_PASSWORD`)

## ดูจากที่ไหนก็ได้ด้วย Tailscale (เลือกใช้)

Pi ต่อฮอตสปอตมือถือหรือ Wi-Fi ที่มีเน็ตเหมือนเดิม แล้วรัน `bash setup_tailscale.sh` บน Pi
ลงแอป Tailscale บนมือถือ ล็อกอินบัญชีเดียวกัน แล้วเปิด `http://<IP 100.x ของ Pi>:5000`
ที่อยู่นี้ไม่เปลี่ยนแม้ย้าย Wi-Fi / ถ้าเน็ตหลุด เครื่องยังตรวจและไล่นกได้ตามปกติ

## ข้อมูลสำหรับเทรนโมเดล (เฉพาะเวอร์ชัน train)

ระบบเก็บภาพดิบลง `~/bird_images/dataset/` เอง (เจอนก ก้ำกึ่ง มีการเคลื่อนไหว สุ่ม ทุกครั้งที่สั่งไล่
และทุกครั้งที่กด "ถ่ายภาพเดี๋ยวนี้") พร้อมไฟล์ `.json` เก็บกรอบที่โมเดลเห็น

v7.2 ลดภาพซ้ำ: ภาพอัตโนมัติที่แทบเหมือนภาพที่เก็บล่าสุด (กรอบอยู่ที่เดิม) ไม่เก็บ
ก้ำกึ่ง/PIR/เคลื่อนไหว มีระยะห่างขั้นต่ำ (`DATASET_GAP_S`) ภาพสุ่มเก็บตามเวลา (`DATASET_RANDOM_GAP_S`)
ภาพเยอะแล้ว: การ์ดเทรน → **🧹 ลบภาพซ้ำ** (ไม่แตะภาพที่ติดป้ายและภาพที่กดถ่ายเอง)
หรือ **🗑 ลบทั้งหมดในแท็บนี้** (แท็บยังไม่ติดป้าย / ไม่มีนก) — ลบแล้วกู้ไม่ได้ ดาวน์โหลด ZIP ไว้ก่อนถ้าจะเก็บ
ภาพที่ขึ้นเป็น ? คือไฟล์เสียจากไฟดับตอนเขียน v7.2 ลบให้เองตอนเปิดเซิร์ฟเวอร์ และเขียนภาพใหม่แบบไฟดับไม่เสีย
ปิดเครื่องด้วย `sudo shutdown -h now` รอไฟเขียวบน Pi ดับก่อนถอดไฟ

1. หน้าเว็บ → การ์ด **"ข้อมูลสำหรับเทรนโมเดล"** แตะภาพแล้วติดป้าย
   **✓ มีนก** (กรอบถูก) / **✗ ไม่มีนก** / **✎ กรอบผิด** / 🗑 ลบภาพเสีย — ติดแล้วเลื่อนไปภาพถัดไปเอง
   (คีย์บอร์ด: 1 / 2 / 3 / ลูกศร) ภาพที่ระบบเห็นผิด (สั่งไล่ทั้งที่ไม่มีนก) สำคัญที่สุด
2. กด **⬇ ZIP เฉพาะที่ติดป้าย** ได้ไฟล์รูปแบบ YOLO: `images/` `labels/` `data.yaml` และ
   `review_needed.txt` (ภาพที่ต้องแก้กรอบ) — กรอบจากโมเดลใส่ไว้ให้แล้ว แก้เฉพาะที่ผิด
3. อัปโหลดเข้า Roboflow (หรือ CVAT) แก้กรอบใน `review_needed.txt` → เทรนบน Google Colab
   `yolo detect train model=yolov8n.pt data=data.yaml epochs=100 imgsz=640`
4. แปลงเป็น NCNN `yolo export model=best.pt format=ncnn` แล้ววางทับ `~/bird/yolov8n_ncnn_model`
   (สำรองของเดิมก่อน) เซิร์ฟเวอร์หาเลขคลาส bird ของโมเดลใหม่ให้เอง

## ค่าที่ปรับได้ (ต้นไฟล์ `raspberry_pi_server.py`)

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `AUTO_INTERVAL_S` | 5 | ตรวจทุกกี่วินาที |
| `BURST_FRAMES` | 3 | ถ่ายรัวกี่เฟรมต่อรอบ (เจอนกแล้วหยุด) |
| `DETECT_CLAHE` | True | เพิ่มคอนทราสต์ก่อนตรวจ ช่วยตอนภาพสว่างจ้า |
| `ROI_CROP` | True | ตัดภาพตาม ROI ก่อนตรวจ |
| `CONFIRM_FRAMES` | 2 | ต้องเจอนกติดกันกี่เฟรมถึงจะไล่ |
| `CONFIRM_CONF` | 0.20 | เกณฑ์ของเฟรมยืนยัน (เฟรมแรกยังใช้เกณฑ์ปกติ) |
| `CONFIRM_DELAY_S` | 3 | เจอเฟรมแรกแล้ว ถ่ายเฟรมยืนยันตามในกี่วินาที (0 = ทันที) |
| `ROI_DEFAULT` | ตัดซ้าย-ขวา 20% | ROI เริ่มต้น (เปิดอยู่) |
| `PUMP_BUTTON_MS` | 3000 | ปุ่มปั๊มบนหน้าเว็บเปิดกี่ ms (บอร์ด v7.9 ใช้เวลาเท่ารอบไล่ที่ตั้งจากเว็บแทน) |
| `REPEL_MAX_PER_HOUR` | 20 | ไล่อัตโนมัติได้กี่ครั้งต่อชั่วโมง |

ในเฟิร์มแวร์: `REPEL_PUMP_MS_DEF` (3 วินาที ≈ 75-100 มล.) คือเวลาเปิดปั๊มต่อรอบไล่ (ปรับจากเว็บได้) / `PUMP_DUTY_MAX_MS` (60 วินาทีต่อ 10 นาที) คือเพดานเวลาปั๊มรวม
กันปั๊มเดินแห้งตอนยังไม่มีเซนเซอร์น้ำ

การกวาดหัวฉีดตอนไล่: ค่าเริ่มต้น **±40° ที่ความเร็ว 30%** (`REPEL_SWEEP_DEG_DEF` / `REPEL_SPEED_PCT_DEF`)
ปรับได้จากหน้าเว็บ การ์ด "ควบคุมด้วยมือ" → "การกวาดตอนไล่นก" (บอร์ดจำค่าไว้ในแฟลช)
กด "ทดสอบกวาด (ไม่ฉีดน้ำ)" เพื่อดูว่าหัวฉีดชนขอบไหม — ชนขอบให้ลดความกว้าง เหวี่ยงแรง/สะดุดให้ลดความเร็ว
ถ้าหัวฉีดเคยชนขอบหรือถูกมือดัน ตำแหน่งจะเพี้ยน: จัดหัวฉีดให้ตรงกลางแล้วกด "ตั้งตรงนี้เป็นจุดกลาง"
