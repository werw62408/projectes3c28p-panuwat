# เครื่องไล่นกอัตโนมัติ

| ไฟล์ | ใช้ที่ไหน |
|---|---|
| `controller_board_esp32/controller_board_esp32.ino` | แฟลชลง ESP32 (Board = ESP32 Dev Module) — เฟิร์มแวร์ **BIRDCTRL v7.1** |
| `raspberry_pi_server.py` | รันบน Raspberry Pi — เซิร์ฟเวอร์ **v6.1** (ใช้คู่กับเฟิร์มแวร์ v7.1) |
| `sim/` | ชุดจำลองสำหรับทดสอบบนคอม Linux ไม่ต้องใช้บน Pi |

ต้องอัปเดต **ทั้งสองไฟล์พร้อมกัน** เพราะรูปแบบข้อความตอนบอร์ดบูตเปลี่ยนไป

## ไฟสถานะ

| ไฟ | ต่อที่ | ความหมาย |
|---|---|---|
| เขียว | รีเลย์ช่อง 2 (GPIO19) | พร้อม: Pi คุยกับบอร์ดอยู่ และกล้องออนไลน์ |
| ส้ม | รีเลย์ช่อง 3 (GPIO26) | เจอนก: ติดทันทีที่ตรวจเจอ ค้าง 10 วินาที (`BIRD_LAMP_HOLD_MS`) แล้วดับเอง |
| แดง | หน้าสัมผัส NO ของปุ่มฉุกเฉิน | กดปุ่มฉุกเฉินอยู่ (ไม่ได้ต่อกับ ESP32) |

ไฟส้มไม่ขึ้นกับโหมดไล่อัตโนมัติ ทดสอบได้แม้ `TEST_MODE = True`

## ทดสอบ PIR → กล้อง → ไฟส้ม กับของจริง

1. เปิดหน้าเว็บ เอาเครื่องหมายออกจาก "ตรวจอัตโนมัติ" (จะได้รู้ว่าภาพที่ถ่ายมาจาก PIR จริง)
2. รอช่อง **PIR** บนหน้าเว็บเปลี่ยนจาก "อุ่นเครื่องอีก N วิ" (60 วินาทีหลังบอร์ดบูต)
3. ถือภาพนกไว้หน้ากล้อง แล้วโบกมือผ่าน PIR
4. ข้อความใต้ภาพต้องขึ้น **"PIR ทริก → พบนก 1 ตัว"** และไฟส้มติด (ช่อง "ไฟส้ม (เจอนก)" = ติด)
5. เอานกออก รอ 10 วินาที ไฟส้มต้องดับเอง
6. ปุ่ม **💡 ทดสอบไฟส้ม** ใช้เช็กสายรีเลย์ช่อง 3 ได้โดยไม่ต้องรอเจอนก

PIR ทริกซ้ำได้ทุก 5 วินาที (`PIR_LOCKOUT_MS`)

## สิ่งที่ต้องทำหลังอัปเดต

1. **ตั้งจุดกลางมอเตอร์ทุกครั้งที่เปิดเครื่อง** — หมุนหัวฉีดให้อยู่ตรงกลาง แล้วกด
   "⌖ ตั้งตรงนี้เป็นจุดกลาง" บนหน้าเว็บ (ถ้ายังไม่ได้ตั้ง หน้าเว็บจะเตือนสีเหลือง)
2. **ตั้ง PIN** ถ้ามีคนอื่นต่อ Wi-Fi / ฮอตสปอตเดียวกัน
   ใส่ `Environment=BIRD_PIN=4821` ในไฟล์ `bird.service` ใต้ `[Service]`
3. **เปิด ROI ให้กรอบแคบรอบจุดที่นกชอบเกาะ** — ระบบจะตัดภาพเฉพาะกรอบก่อนตรวจ
   ทำให้เจอนกตัวเล็กได้ดีขึ้นมาก
4. ก่อนใช้งานจริง แก้ `TEST_MODE = False` ใน `raspberry_pi_server.py`

## ค่าที่ปรับได้ (ต้นไฟล์ `raspberry_pi_server.py`)

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `AUTO_INTERVAL_S` | 5 | ตรวจทุกกี่วินาที |
| `BURST_FRAMES` | 3 | ถ่ายรัวกี่เฟรมต่อรอบ (เจอนกแล้วหยุด) |
| `DETECT_CLAHE` | True | เพิ่มคอนทราสต์ก่อนตรวจ ช่วยตอนภาพสว่างจ้า |
| `ROI_CROP` | True | ตัดภาพตาม ROI ก่อนตรวจ |
| `CONFIRM_FRAMES` / `CONFIRM_OF` | 2 / 3 | ต้องเจอกี่ครั้งในกี่รอบล่าสุดถึงจะไล่ |
| `REPEL_MAX_PER_HOUR` | 20 | ไล่อัตโนมัติได้กี่ครั้งต่อชั่วโมง |

ในเฟิร์มแวร์: `PUMP_DUTY_MAX_MS` (60 วินาทีต่อ 10 นาที) คือเพดานเวลาปั๊มรวม
กันปั๊มเดินแห้งตอนยังไม่มีเซนเซอร์น้ำ

## ทดสอบกับคลิปที่อัดไว้ (ไม่ต้องมีเว็บแคม)

```bash
BIRD_CAM=~/clip.mp4 python3 raspberry_pi_server.py
```

## ชุดจำลอง (สำหรับนักพัฒนา, Linux)

```bash
cd sim
./build.sh                    # คอมไพล์เฟิร์มแวร์ให้รันบนคอม
python3 fw_test.py            # ทดสอบเฟิร์มแวร์ผ่าน Serial จำลอง
python3 web_test.py --clip clip.mp4 --model yolov8n.pt   # จำลองใช้หน้าเว็บจากมือถือ
```
