# เคส SomudTick v1 + แผนต่อสาย (ฮาร์ดแวร์ v12)

ทรง Game Boy ตั้งตรง ขนาด **94.2 × 137.2 × 27.5 มม.** (อัปเดตตามขนาดที่วัดจริง: จอใหญ่, NA011, แบต 48×30×10, ลำโพง, DS3231)

ของข้างในวางตรงไหน: `out/inside_layout.png` (มองจากด้านหลัง) · ลองปุ่มก่อนพิมพ์ทั้งเคส: `out/na_test.stl`
- **บน:** จอ OLED 0.91"
- **กลาง:** จอใหญ่ ES3C28P วางแนวนอน (ตั้งค่าในเครื่อง: Settings → Screen → **Wide**)
- **ล่าง:** บอร์ดปุ่ม NA011 (จอยซ้าย, A B C D ขวา, F E ตรงกลาง)

ดูรูป: `out/preview.png` (ตัวเคส), `../wiring_v12.png` (สายไฟ)

## 0. ก่อนพิมพ์: เช็คขนาดกับของจริง
ตัวเลขส่วนใหญ่มาจากแบบของผู้ผลิต:
- ES3C28P: วัดจากเส้นในไฟล์ `ES3C28P_Size.pdf` เช่น รูน็อตห่าง 78 × 42 มม. และจอที่มองเห็นเยื้องจากกลางบอร์ด 3.07 มม.
- NA011: ขนาด 87 × 54 มม. ตามเอกสารผู้ขาย ส่วนตำแหน่งปุ่ม**อ่านจากรูปสินค้า** อาจคลาดได้ 1–2 มม.

1. พิมพ์ `out/template_1to1.pdf` ที่ **100 %** (ห้ามเลือก "Fit to page") แล้ววัดเส้นใต้ภาพว่ายาว 100 มม. จริง
2. วางบอร์ดจริงบนกระดาษ ให้ขอบตรงกับเส้นประสีเทา แล้วดูว่า
   - วงสีน้ำเงิน (รูบนหน้าเคส) ตรงกับจอย ปุ่ม และจอ
   - วงสีแดง (รูน็อต) ตรงกับรูบนบอร์ด
3. ถ้าไม่ตรง แก้ตัวเลขใน `make_case.py` (บรรทัดที่มีคำว่า `MEASURE`) แล้วรัน `python make_case.py` ใหม่
   - หรือส่งค่าที่วัดได้มา เดี๋ยวแก้ให้
4. จะเช็คด้วยพลาสติกก่อนก็ได้: พิมพ์ `fit_test.stl` (หน้าเคสบาง 1.2 มม. ประมาณ 15 นาที)

**ค่าที่ยังเป็นค่าประมาณ:**
| ค่า | ในไฟล์ | ตอนนี้ |

**ลองปุ่มก่อน: `na_test.stl`** (หน้าเคสส่วนปุ่ม 2 แผ่นในไฟล์เดียว, ~20 นาที, หน้าคว่ำลงถาด ไม่ต้องซัพพอร์ต)
- ครอบลงบน NA011: ขา 4 มุมวางบนมุมบอร์ด ตัว L ล็อกขอบบอร์ด
- แผ่นบนรูจอย 26 มม., แผ่นล่าง 32 มม. โยกจอยให้สุดทุกทิศ ดูว่าอันไหนไม่ติด
- ดูว่าปุ่มสี/E/F อยู่กลางรูไหม ถ้าเยื้อง บอกว่าเยื้องไปทางไหนกี่ มม.

## 1. ชิ้นที่ต้องพิมพ์ (PETG หรือ PLA, ชั้น 0.2 มม., ผนัง 3 เส้น, ไส้ใน 20 %)
| ไฟล์ | จำนวน | วางพิมพ์ | ซัพพอร์ต |
|---|---|---|---|
| `front_shell.stl` | 1 | **หน้าเคสคว่ำลงถาด** | ไม่ต้อง (รู USB/IR/สวิตช์ที่ผนังเป็นสะพานสั้น) |
| `back_plate.stl` | 1 | ด้านนอกลงถาด | ไม่ต้อง |
| `btn_cap.stl` | 4 | ด้านกดลงถาด | ไม่ต้อง |
| `small_cap.stl` | 2 | ด้านกดลงถาด | ไม่ต้อง |

ทุกชิ้นตรวจแล้วว่าเป็นทรงปิดสนิท (ไม่มีรูรั่วในโมเดล) และพื้นที่หน้าเคสตรงกับที่คำนวณทุกทศนิยม

## 2. ของที่ต้องใช้
- น็อต **M3×8** ×4: ยึดจอเข้าเสาทองเหลืองเดิม (ขันจากด้านหลังผ่านเสาในฝาหลัง)
- น็อตเกลียวปล่อย **M2.5×8** ×4: ปิดฝาหลังที่มุม
- น็อตเกลียวปล่อย **M2.5×16** ×2: ยึด NA011 (ผ่านฝาหลัง → ตัวรอง → บอร์ด → เสาในหน้าเคส)
- สวิตช์เลื่อน **SS12D00** (ตัดไฟแบต, ช่องที่ผนังขวา)
- แบต LiPo **48×30×10 มม.** มีรั้วกั้นที่ฝาหลังหลังจอ (แปะเทปโฟม)
- ลำโพงกลม 16 มม. มีหู (ยาวรวม 30) หนา 10: หมุด 4 ตัวรอบตะแกรงที่ฝาหลัง หูวางตามแนวตั้ง หยดกาวร้อน
- DS3231 และ PCF8574 แปะเทปโฟมที่ฝาหลังส่วนบน (ตำแหน่งตาม `out/inside_layout.png`)
- เทปโฟมสองหน้า, กาวร้อน, สายซิลิโคน 26–28 AWG, ท่อหด

## 3. เตรียมบอร์ดก่อนประกอบ
1. **NA011:**
   - เลื่อนสวิตช์ไปที่ **3V3**
   - ตัดขาทองแดงยาว ๆ ด้านใต้ (ขาเสียบ Arduino) ให้เหลือราว 2 มม. เคสเผื่อที่ใต้บอร์ดไว้ 3 มม.
   - จะใช้ปุ่มสีเดิมเลยก็ได้ หมวก `btn_cap` ครอบทับลงไป
2. **PCF8574:**
   - ดูตัวหนังสือบนชิป ถ้าเป็น `PCF8574` ให้ต่อจัมเปอร์ A0 A1 A2 ลง GND ทั้งหมด = address 0x20
   - ถ้าเป็น **`PCF8574A`** ห้ามตั้งเป็น 0x38 (ชนทัช) หรือ 0x3C (ชน OLED)
3. **OLED:** ถอดขา header ออก แล้วบัดกรีสายตรงที่รูแทน โมดูลจะบางลงและลงช่องพอดี

## 4. ต่อสาย (ดูรูป `../wiring_v12.png`: ขาที่มีป้ายสีเดียวกันต่อถึงกัน)
บล็อกขาเหลืองบน NA011 (มุมขวาบน):
```
 V   A   C   E   K   X
 G   B   D   F   3V  Y
```
ใช้ 10 ขา: **3V G A B C D E F K X Y** ส่วน **V ไม่ต้องต่อ**
(V = ไฟหลังผ่านสวิตช์ 3V3/5V → สวิตช์อยู่ 3V3 จะต่อถึง 3V เอง ใช้มิเตอร์เช็ค 3V ↔ V ต้องปี๊บ)

| จาก | ไป | หมายเหตุ |
|---|---|---|
| ES3C28P ขั้ว I2C: SDA (IO16) | PCF8574 SDA, OLED SDA, DS3231 SDA | ต่อพ่วงกันได้ (PCF8574 มีขา IN/OUT) |
| ES3C28P ขั้ว I2C: SCL (IO15) | PCF8574 SCL, OLED SCL, DS3231 SCL | |
| ES3C28P ขั้ว I2C: 3.3V | PCF VCC, OLED VCC, DS3231 VCC, NA011 **3V**, IR กลาง | ใช้ **3.3V เท่านั้น**. NA011 ขา **V ไม่ต้องต่อ** (ได้ไฟจาก 3V ผ่านสวิตช์ที่ตั้งไว้ 3V3) |
| ES3C28P ขั้ว I2C: GND | GND ทุกตัว, NA011 **G**, IR − | |
| PCF8574 P0 / P1 / P2 / P3 | NA011 **A / B / C / D** | บล็อกขา 2×6 บน NA011 |
| PCF8574 P4 / P5 / P6 | NA011 **E / F / K** | K = กดจอย |
| ES3C28P EXP IO2 | NA011 **X** | แกนจอย |
| ES3C28P EXP IO3 | NA011 **Y** | |
| ES3C28P EXP IO21 | IR LED **S** | เหมือนเดิม |
| ES3C28P EXP IO14 | – | **ว่างแล้ว** (ปุ่มจอยย้ายไป PCF8574) |
| แบต + → สวิตช์ → ES3C28P BAT + | | **เช็คขั้วก่อนเสียบ** ปลั๊ก 1.25 มม. สีสายไม่มีมาตรฐาน |
| แบต − → ES3C28P BAT − | | |
| ES3C28P SPK → ลำโพง | | |

✅ **เช็คหลังต่อ (ยังไม่ต้องใส่เคส):** เปิดเครื่อง → Settings → About
- ต้องขึ้น `Small screen OK`, `Buttons OK (0x20)`, `Clock module OK`
- กด B ต้องเปลี่ยนแท็บ, โยกจอยต้องมีวงส้มขยับ

## 4.1 เดินสายในเคส (ดูรูป `../wiring_harness_v12.png`)
รูปนี้**มองจากด้านหลัง** (ถอดฝาหลังออก) ซ้ายขวาจึงสลับกับตอนมองจากหน้า
- **ชั้นที่ 1 (หน้าเคส):** ของที่ยึดอยู่กับหน้าเคส
- **ชั้นที่ 2 (ฝาหลัง):** แบตกับลำโพง

**หลักการเดินสาย**
- **I2C ต่อพ่วงเป็นทอด ไม่ต้องตัดต่อกลางสาย:**
  - ES3C28P → PCF8574 (ขา IN) → PCF8574 (ขา OUT) → DS3231 (หัว 4 ขา) → DS3231 (หัว 6 ขา) → OLED
  - บอร์ด PCF8574 และ DS3231 มีหัวต่อสองฝั่งที่ต่อถึงกันอยู่แล้ว จึงไม่มีจุดตัดต่อกลางสาย I2C เลย
- **จุดร่วม (สาย 2 เส้นบัดกรีลงขาเดียวกัน) มี 4 จุด:**
  | จุด | ที่ไหน | สายที่รวม |
  |---|---|---|
  | J1 | PCF8574 หัว OUT ขา VCC | W8 (ไป DS3231) + W25 (ไป NA011 ขา 3V) |
  | J2 | PCF8574 หัว OUT ขา GND | W7 (ไป DS3231) + W26 (ไป NA011 ขา G) |
  | J3 | OLED ขา VCC | W12 (มาจาก DS3231) + W13 (ไป IR ขากลาง) |
  | J4 | OLED ขา GND | W11 (มาจาก DS3231) + W14 (ไป IR ขา −) |
  - วิธีทำ: บิดปลายสาย 2 เส้นเข้าด้วยกันก่อน แล้วค่อยเสียบรูหรือวางบนขาแล้วบัดกรีทีเดียว
- **จุดตัดต่อกับสายปลั๊ก 1.25 มม. ของบอร์ดจอ (S1–S4):**
  - ถ้าสายปลั๊กที่มากับบอร์ดยาวพอ บัดกรีตรงเข้าโมดูลเลยก็ได้ จุดต่อจะน้อยลง
  - ถ้าต้องต่อสาย ให้ต่อแบบวางเหลื่อมกันทีละ 8 มม. ห่อท่อหดทีละเส้น แล้วหุ้มรวมอีกชั้น
  - สาย IO14 ในปลั๊ก expansion ไม่ได้ใช้แล้ว ตัดทิ้งแล้วหุ้มท่อหดปลายไว้
- **ปุ่ม 7 ปุ่ม** ใช้สายแพ 7 เส้น (rainbow ribbon) เส้นเดียว สั้นและเรียบร้อย
- **สายไปฝาหลัง** (แบต W27, W29 และลำโพง W30, W31) เผื่อยาวอีก ~6 ซม. ให้เปิดฝาหลังพับขึ้นด้านบนได้โดยไม่ดึงสาย
- **ข้างช่อง USB-C (ผนังซ้ายเมื่อมองจากหน้า):** อย่าเดินสายขวางช่องนี้ ต้องเหลือทางให้หัวสายเสียบได้
- **รัดสาย:** หยดกาวร้อนเล็ก ๆ ยึดกลุ่มสายกับหลังบอร์ดจอทุก 3–4 ซม. และที่โคนจุดบัดกรีทุกจุด (กันขาดตอนเปิดปิดเคส)

**ลำดับบัดกรี** (ทดสอบทีละขั้น จะได้รู้ทันทีว่าพังตรงไหน)
1. I2C: ES3C28P → PCF8574 (W1–W4) → เปิดเครื่อง About ต้องขึ้น `Buttons OK`
2. PCF8574 → NA011 (W18–W26) และขา X/Y (W16, W17) → ลองกดปุ่มทุกปุ่ม และโยกจอย
3. PCF8574 → DS3231 (W5–W8) → About ต้องขึ้น `Clock module OK`
4. DS3231 → OLED (W9–W12) → รีสตาร์ต ต้องเห็นนาฬิกาบน OLED
5. IR (W13–W15) → Apps → AC ลองกดส่ง ส่องหลอด IR ด้วยกล้องมือถือต้องเห็นแสงม่วง ๆ
6. แบต + สวิตช์ + ลำโพง (W27–W31) → **เช็คขั้วแบตก่อนเสียบ**

**ตัดสาย** (ความยาวเผื่อไว้แล้ว ให้ตัดเกินอีก +2 ซม. แล้วค่อยเล็มตอนจัดจริง)
| สาย | จาก → ถึง | สัญญาณ | ขนาด | ตัดยาว (มม.) |
|---|---|---|---|---|
| W1–W4 | ปลั๊ก I2C ของจอ → PCF8574 IN | SDA, SCL, GND, 3V3 | 28 / 28 / 26 / 26 AWG | 80 |
| W5–W8 | PCF8574 OUT → DS3231 (หัว 4 ขา) | SDA, SCL, GND, 3V3 | 28 AWG | 95 |
| W9–W12 | DS3231 (หัว 6 ขา) → OLED | SDA, SCL, GND, 3V3 | 28 AWG | 90 |
| W13, W14 | OLED → IR | 3V3, GND | 28 AWG | 75 |
| W15 | ปลั๊ก EXP IO21 → IR S | IR | 28 AWG | 75 |
| W16, W17 | ปลั๊ก EXP IO2 / IO3 → NA011 X / Y | แกนจอย | 28 AWG | 125 |
| W18–W24 | PCF8574 P0–P6 → NA011 A B C D E F K | ปุ่ม (สายแพ 7 เส้น) | 28 AWG | 60 |
| W25, W26 | PCF8574 OUT VCC / GND → NA011 3V / G | ไฟ NA011 | 26 AWG | 65 |
| W27 | แบต + → สวิตช์ | แบต | 24 AWG | 160 |
| W28 | สวิตช์ → ปลั๊ก BAT + ของจอ | แบต | 24 AWG | 90 |
| W29 | แบต − → ปลั๊ก BAT − ของจอ | แบต | 24 AWG | 125 |
| W30, W31 | ลำโพง → ปลั๊ก SPK ของจอ | ลำโพง | 26 AWG | 150 |

**รวมประมาณ 2.8 เมตร** แนะนำซื้อ:
- สายซิลิโคน 28 AWG 3–4 สี อย่างละ 2 ม.
- สาย 24 AWG แดง/ดำ อย่างละ 50 ซม.
- สายแพ rainbow 10 เส้น 20 ซม.
- ท่อหด 1.5 มม. และ 3 มม.

⚠️ ตำแหน่งปลั๊กบนหลังบอร์ดจอในรูปเป็นค่าประมาณจากแบบของผู้ผลิต (เรียงตามแนวขอบบน) ลำดับจริงให้ดูตัวหนังสือบนบอร์ด ความยาวอาจคลาดได้ ±2 ซม. จึงให้ตัดเผื่อไว้
แก้ตำแหน่งได้ในไฟล์ `make_harness.py` แล้วรันใหม่: `python make_harness.py`

## 5. ประกอบ
1. OLED ลงช่องบนหน้าเคส (หน้าจอคว่ำลง) หยดกาวร้อน 2 จุดที่ขอบ
2. จอใหญ่: กระจกลงกรอบ (ด้าน USB-C อยู่ทางซ้ายเมื่อมองจากหน้า) PCB จะวางบนปุ่มรอง 4 จุด
3. ใส่หมวกปุ่ม `btn_cap` 4 ตัว และ `small_cap` 2 ตัว ลงรูจากด้านใน แล้ววาง NA011 ทับ ให้จอยโผล่ออกรูใหญ่
4. แบตลงช่องบนฝาหลัง (เทปโฟม) ลำโพงแปะหลังตะแกรง สวิตช์ใส่ช่องผนังขวาแล้วหยดกาว
5. ปิดฝาหลัง:
   - M3×8 ×4 ขันเข้าเสาทองเหลืองของจอ
   - M2.5×16 ×2 ขันผ่าน NA011
   - M2.5×8 ×4 ขันที่มุม
6. เปิดเครื่อง → Settings → Screen → **Wide** ถ้าภาพ OLED กลับหัว เลือก `Small screen: Upside down`

## 6. ข้อจำกัดที่รู้อยู่
- **ช่องการ์ด SD** อยู่ขอบล่างของจอใหญ่ หันเข้าหา NA011 เอาการ์ดเข้าออกต้องเปิดฝาหลัง (ส่งรูป/เกมผ่านหน้าเว็บได้ตามปกติ)
- **ปุ่ม BOOT/RESET บนบอร์ด** กดจากนอกเคสไม่ได้ แต่ไม่จำเป็น:
  - ตั้งทัชใหม่: Settings → Fix touch
  - แฟลช: Settings → About → Update firmware
