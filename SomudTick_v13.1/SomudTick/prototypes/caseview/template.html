เปิดไฟล์ .stl เพื่อสั่งพิมพ์

มือถือเปิด .stl ตรง ๆ ไม่ได้ ต้องเปิดในโปรแกรมสไลซ์ (slicer) บนคอม แล้วกดสไลซ์ส่งเข้าเครื่องพิมพ์:

  • Bambu Studio (เครื่อง Bambu) · OrcaSlicer (ใช้ได้เกือบทุกเครื่อง) · Ultimaker Cura (Creality, Ender)
  • ในโปรแกรม: File → Import → เลือกไฟล์ .stl หรือลากไฟล์ไปวางในหน้าต่าง
  • ถ้าไม่มีเครื่องพิมพ์: ส่งไฟล์ .stl ให้ร้านรับพิมพ์ 3D ได้เลย บอกว่า PETG หรือ PLA ชั้น 0.2 มม.
