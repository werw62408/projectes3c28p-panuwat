# SomudTick (สมุดติ๊ก) v11.6: firmware สำหรับบอร์ด ES3C28P

## ของใหม่ใน v11.6 (เกมมังกร + นาฬิกา Sudoku + อากาศสาทร + อัปคลิปจาก iPhone)

ดูหน้าตาได้ในรูป `preview_v11.6_dragon.png`, `preview_v11.6_tall.png`, `preview_v11.6_wide.png`

### 0. วิธีแฟลช (อ่านก่อน: ช่อง address มีค่า `0x1000` ใส่ไว้ตั้งแต่แรก)
รอบ v11.5 บอร์ดวนรีสตาร์ต เพราะแฟลชไฟล์ app ที่ `0x1000` (ศูนย์ขาดไป 1 ตัว) ช่อง Flash Address ใน esptool-js มีค่า `0x1000` ใส่ไว้ตั้งแต่เปิดหน้าเว็บ ต้อง**ลบให้หมดแล้วพิมพ์ใหม่**ทุกครั้ง
1. บนบอร์ด: Settings → About → **Update firmware** → **Restart** (จอขาว "Update mode")
2. เปิด https://espressif.github.io/esptool-js/ ใน Chrome หรือ Edge ตั้ง Baudrate `115200` กด **Connect** เลือกพอร์ต
   ✅ **เช็ค:** ขึ้น `Connected to device: ESP32-S3`
3. ช่อง **Flash Address**: ลบค่าเดิมให้หมด แล้วพิมพ์ **`0x10000`** (หนึ่ง ตามด้วยศูนย์ **4 ตัว**) แล้วเลือกไฟล์ **`SomudTick_app.bin`**
   ✅ **เช็คก่อนกด Program:** นับเลขศูนย์หลัง `0x1` ต้องมี **4 ตัว** (`0x10000`) ไม่ใช่ 3 ตัว (`0x1000`)
4. กด **Program** รอจนกล่องดำขึ้น `Wrote ... at 0x10000`
   ✅ **เช็ค:** บรรทัดนั้นต้องลงท้ายด้วย **`at 0x10000`**
   ❌ ถ้าเห็น `at 0x1000` หรือบอร์ดวนรีสตาร์ต: ไม่ต้องตกใจ บันทึก log ไม่หาย ให้แก้ตามหัวข้อ "ถ้าบอร์ดวนรีสตาร์ต" ด้านล่าง
5. ถอดสาย USB แล้วปิดและเปิดสวิตช์
   ✅ **เช็ค:** Settings หน้าแรก แถว About ขึ้น **`v11.6, xx%`** และ Wi-Fi กับ PIN ยังอยู่ครบ

**ถ้าบอร์ดวนรีสตาร์ต (แฟลชผิด address):**
1. ปิดสวิตช์ ถอด USB เปิดกล่อง **กดปุ่ม BOOT ค้าง** แล้วเสียบ USB นับ 1–2 ค่อยปล่อย (บอร์ดจะนิ่ง ไม่วน)
2. esptool-js กด Connect → ช่อง Flash Address ลบแล้วพิมพ์ **`0x0`** → เลือก **`SomudTick_merged.bin`** → Program
3. ปิด/เปิดสวิตช์ จะขึ้นหน้าปรับทัช (การตั้งค่าเริ่มใหม่) ส่วนบันทึก log ยังอยู่ครบ

### 1. Pixel Swim เปลี่ยนเป็น **Dragon** (มังกรบินในอวกาศ)
- ตัวเราเป็นมังกรขาวดำตัวเล็ก (หัวมีเขา ปากอ้ามีฟัน ปีกค้างคาวกระพือ ตัวยาวมีเกล็ดและหนามหลัง หางปลายแหลม) ตัวกับหางโค้งตามทางที่บินผ่าน
- ฉากหลังเป็นท้องฟ้ากลางคืนเต็มไปด้วยดาว (2000 เม็ด เดิม 1400) มังกรบินผ่านตรงไหน ดาวจะแหวกออกและสว่างขึ้น
- โยกจอย = บิน (เหมือนเดิม) / **กดจอย = พุ่ง** (บินเร็วสั้น ๆ มีเส้นลมตามหลัง พักครู่หนึ่งถึงพุ่งได้อีก) / กดจอยค้าง 1 วินาที = ออก
- ชนจุดสี (มี 3 จุด) = ได้คะแนนและตัวโตขึ้น ตัวใหญ่ถึงขนาดหนึ่ง = ขึ้นด่านใหม่ (กลับมาตัวเล็ก)
- หยุดเกม: แตะปุ่ม **Pause** บนแถบดำด้านบน (เพราะกดจอยใช้พุ่งแล้ว) แล้วกดจอยเพื่อเล่นต่อ
- คะแนนสูงสุด (Best) ใช้ต่อจาก Pixel Swim

✅ **เช็ค:** Apps → Games → **Dragon** กดจอยเริ่ม โยกไปมา มังกรต้องบินตามและดาวแหวกออก กดจอย 1 ครั้งมังกรต้องพุ่งไปข้างหน้า
❌ ถ้ามังกรบินผิดทิศ: Settings → Joystick direction ทำใหม่

### 2. นาฬิกา Sudoku ไม่เดินตอนเปิดหน้าต่าง New game แล้ว
- เดิม (เห็นในวิดีโอ): เปิดหน้าต่างเลือกระดับค้างไว้ นาฬิกายังเดิน 0:18 → 0:22
- ตอนนี้: นาฬิกาหยุดตอนเปิดหน้าต่าง New game และหน้าต่าง Solved และตอนจอดับ ส่วนตอนนั่งคิดยังเดินต่อเหมือนเดิม

✅ **เช็ค:** เปิด Sudoku แตะ **New** ค้างไว้ 10 วินาที ตัวเลขเวลาต้องไม่ขยับ แตะนอกหน้าต่างเพื่อปิด แล้วเวลาต้องเดินต่อ

### 3. สภาพอากาศและ PM2.5 เป็นของสาทร กรุงเทพฯ
ตำแหน่ง: มหาวิทยาลัยเทคโนโลยีราชมงคลกรุงเทพ ถนนนางลิ้นจี่ แขวงทุ่งมหาเมฆ เขตสาทร (พิกัด 13.71, 100.54 จาก OpenStreetMap) บนจอเขียนว่า `Sathorn, BKK`

✅ **เช็ค:** Apps → Internet → Weather บรรทัดบนสุดของการ์ดอากาศต้องเป็น `Sathorn, BKK`

### 4. อัปคลิปจาก iPhone ได้แล้ว
- เดิม: ใน Safari บน iPhone (iOS 18.5) ขึ้น "แปลงคลิปนี้ไม่ได้ (มือถือไม่ยอมเปิดภาพในคลิป)" ทุกคลิป
- สาเหตุ: Safari บน iPhone จะไม่ถอดภาพจากคลิปถ้าตัวเล่นคลิปไม่ได้อยู่บนหน้าเว็บ และจะเล่นคลิปได้เฉพาะตอนที่นิ้วแตะเลือกไฟล์ หน้าเว็บเดิมทำผิดทั้งสองข้อ
- ตอนนี้: วางตัวเล่นคลิปไว้บนหน้าเว็บ (เล็กมากจนมองไม่เห็น) และสั่งเล่นทันทีตอนเลือกไฟล์
- ข้อความตอนแปลงไม่ได้ไม่บอกให้ไปเปิด Safari แล้ว (เพราะใช้ Safari อยู่แล้ว) ให้ลองคลิปอื่นหรือแปลงในคอมแทน

✅ **เช็ค:** มือถือ → หน้าเว็บบอร์ด → รูป/คลิป → **เลือกคลิป** (คลิปสั้น 5–10 วินาที) ตัวเลข % ต้องวิ่งจนถึง 100 แล้วขึ้น "ส่งคลิปเสร็จแล้ว" จากนั้นเปิดดูบนบอร์ด Apps → Files → videos
❌ ถ้ายังไม่ได้: ถ่ายหน้าจอข้อความที่ขึ้นส่งมา และบอกว่าคลิปถ่ายเองหรือเซฟมา (ในคอมยังลองแบบ iPhone ของจริงไม่ได้)

### 5. หน้าเว็บบอก SD card ละเอียดเหมือนบนบอร์ด
เดิมขึ้น `ใช้ไป 1 / 3836 MB` ตอนนี้ขึ้น เช่น `ใช้ไป 1.1 MB จาก 3.7 GB · รูป 18 · คลิป 2`

✅ **เช็ค:** มือถือ → รูป/คลิป ใต้ปุ่มเลือกรูปต้องเห็นข้อความแบบนี้

### 6. อื่น ๆ
- PM2.5 ระดับ OK: คำแนะนำเปลี่ยนเป็น `OK for most.` (ข้อความเดิมยาวจนถูกตัดบนจอแนวตั้ง)

### 7. ทดสอบก่อนส่ง
- ตัวจำลองบน Raspberry Pi 5: **ผ่านทั้งหมด 119 ข้อ** (ของใหม่ 6 ข้อ ทุกข้อขึ้น FAIL บน v11.5 และ PASS บน v11.6 ข้อนาฬิกา Sudoku ทำให้อาการเดียวกับในวิดีโอเกิดซ้ำได้ก่อนแก้)
- ตัวแปลงคลิปทดสอบใน Chromium 6 แบบ รวมแบบใหม่ `ios` ที่จำลองข้อจำกัดของ Safari บน iPhone: v11.5 ขึ้นข้อความแปลงไม่ได้แบบเดียวกับมือถือคุณ v11.6 ได้ภาพครบ 90 ภาพพร้อมเสียง
- ภาพหน้าจอมังกร อากาศ Sudoku และหน้า Games ทั้งแนวตั้ง แนวนอน ธีมสว่าง และธีมมืด ดูแล้วไม่มีตัวหนังสือล้นหรือถูกตัด
- **ต้องลองบนบอร์ดจริงและมือถือจริง:** อัปคลิปจาก iPhone, ความลื่นของเกมมังกรบนจอจริง, การแฟลชที่ `0x10000`

### 0. วิธีแฟลชเปลี่ยนแล้ว: ใช้ไฟล์ `SomudTick_app.bin` ที่ `0x10000` (สำคัญ อ่านก่อน)
ไฟล์ `SomudTick_merged.bin` ที่เคยแฟลชที่ `0x0` มีช่องว่าง 20 KB ทับพื้นที่เก็บการตั้งค่า (0x9000–0xDFFF) แฟลชทีไรการตั้งค่าหายหมด เช่น Wi-Fi, PIN, ค่าทัช, Sudoku ที่เล่นค้าง, สวน Garden, คะแนนสูงสุด, วันที่สำรองข้อมูล (บันทึก log ไม่หาย เพราะอยู่คนละที่) ในวิดีโอ หน้า About เคยขึ้น `Backup to SD 26 Sep` แต่หลังแฟลช v11.4 กลายเป็น `never` ก็เพราะเรื่องนี้
ตั้งแต่ v11.5 ให้อัปเดตด้วยไฟล์ `SomudTick_app.bin` ไฟล์เดียว ไฟล์นี้เขียนแค่ตัวโปรแกรม ไม่แตะการตั้งค่า
1. บนบอร์ด: Settings → About → **Update firmware** → **Restart** (จอดับ = พร้อมแฟลช)
2. เปิด https://espressif.github.io/esptool-js/ ใน Chrome หรือ Edge ตั้ง Baudrate `115200` กด **Connect** เลือกพอร์ตของบอร์ด
   ✅ **เช็ค:** กล่องดำขึ้น `Chip is ESP32-S3`
3. ช่อง **Flash Address** พิมพ์ **`0x10000`** (ศูนย์ x หนึ่ง ศูนย์สี่ตัว) แล้วเลือกไฟล์ `SomudTick_app.bin` กด **Program**
   ✅ **เช็ค:** ขึ้น `Hash of data verified`
   ❌ ถ้าเผลอใส่ `0x0` กับไฟล์ app บอร์ดจะเปิดไม่ขึ้น ให้แฟลชใหม่ที่ `0x10000` (ไม่มีอะไรเสีย)
4. ถอดสาย USB แล้วปิด/เปิดสวิตช์ 1 ครั้ง
   ✅ **เช็ค:** Settings หน้าแรก แถว About ต้องขึ้น **`v11.5, 79%`** (เลขแบตของคุณ) และ Wi-Fi, PIN, ค่าทัช ยังอยู่ครบ
- `SomudTick_merged.bin` ยังมีให้ แต่ใช้เฉพาะตอน**ลงบอร์ดใหม่ครั้งแรก**เท่านั้น (ที่ `0x0`) ใช้แล้วการตั้งค่าจะหาย
- ตารางแบ่งพื้นที่ (partition) เหมือน v11.4 ทุกไบต์ log ในเครื่องไม่หาย

### 1. เตือนแล้วจอติดค้าง + มีเสียงติ๊ง
- เดิม: ถึงเวลาเตือน จอติดแล้ว**ดับทันที**ในจังหวะเดียวกัน (โปรแกรมคำนวณเวลาที่ไม่ได้แตะผิดจนกลายเป็น 49 วัน) เห็นแค่ไฟ LED กะพริบ ซึ่งหันเข้าในกล่องจึงแทบมองไม่เห็น
- ตอนนี้: จอติดค้าง ขึ้นแถบ `Time for Water  >` และมี**เสียงติ๊ง-ดิ๊ง**สั้น ๆ ทางลำโพง (ดังตามระดับเสียงใน Settings ถ้าปิดเสียงไว้จะไม่ดัง)

✅ **เช็ค:** เว็บ → กิจกรรม ตั้งเตือน Water เป็น 1 นาที บันทึก แล้วปล่อยให้จอดับ (ช่วง 08:00–22:00) พอครบเวลาจอต้องติดค้าง มีแถบเตือน และได้ยินเสียง
❌ ถ้าจอติดแต่ไม่มีเสียง: เช็ค Settings → Sound volume ว่าไม่ได้ปิด และสายลำโพงเสียบช่อง SPEAKER แน่น

### 2. กันกดจอยในกระเป๋า: กดจอย 2 ครั้งไม่บันทึกเองแล้ว
- เดิม: ถ้าทิ้งกรอบส้มไว้บนปุ่ม +1 ก่อนจอดับ อยู่ในกระเป๋า**กดครั้งแรกจอติด กดครั้งที่สองบันทึก +1 ทันที**
- ตอนนี้: จอดับแล้วกรอบส้มหายไปด้วย และจะกลับไปเริ่มที่ปุ่มแรกของหน้า (ปุ่ม Stats) การโยกครั้งแรกหลังจอติดแค่โชว์กรอบ

✅ **เช็ค:** ใช้จอยพากรอบไปอยู่บน +1 ของ Water แล้วรอให้จอดับ กดจอย 2 ครั้ง ต้องไม่มีบันทึกเพิ่ม และกรอบต้องไม่อยู่บน +1

### 3. เกมที่เปิดทิ้งไว้หยุดเอง จอดับตามปกติ (Pixel Swim, Tilt Maze, Blocks)
- เดิม: เล่นค้างไว้แล้วลืม จอสว่างเต็มค้างจนแบตหมด
- ตอนนี้: ไม่แตะจอและไม่ขยับจอยจนถึงเวลาหรี่จอ เกมจะ**หยุดชั่วคราวเอง** แล้วจอหรี่และดับตามเวลาใน Settings (ถ้าตั้ง Never เกมจะหยุดเองหลัง 5 นาที) กดจอย 1 ครั้ง = แค่ปลุกจอ กดอีกครั้ง = เล่นต่อ

✅ **เช็ค:** ตั้ง Settings → Screen → Screen off after = `1m` เข้า Pixel Swim กดเริ่มแล้ววางไว้ ประมาณ 40 วินาทีต้องขึ้น PAUSED และจอหรี่ 1 นาทีจอดับ

### 4. เกมทุกเกมออกได้ด้วยการกดจอยค้าง 1 วินาที (ครบทุกเกมแล้ว)
| เกม | กดจอยค้าง 1 วินาที | หยุดเกม |
|---|---|---|
| Tilt Maze, Blocks | **กลับหน้า Games** (เดิม = หยุดเกม) | แตะปุ่ม **Pause** บนแถบดำด้านบน (Blocks แตะข้าง ๆ กระดานก็ได้) |
| Garden | **กลับหน้า Games** (เดิมไม่มีอะไรเกิดขึ้น) | - |
| Pixel Swim, Sudoku, Sand | กลับหน้า Games (เหมือนเดิม) | เหมือนเดิม |
- แถบดำบน Tilt Maze และ Blocks มีปุ่ม `Pause` กับ `Exit` แยกกัน (เดิมแตะตรงไหนของแถบก็ออกเลย)

✅ **เช็ค:** เข้า Tilt Maze กดเริ่ม แล้วกดจอยค้าง 1 วินาที ต้องกลับหน้า Games / เข้าใหม่ แตะ `Pause` ต้องขึ้นเมนู PAUSED

### 5. Bluetooth คืนหน่วยความจำหลังสแกน (ข่าวไม่พังแล้ว)
- เดิม (เห็นในวิดีโอ): ก่อนสแกน Free memory 168 KB หลังสแกนเหลือ 74 KB แล้วข่าวทุกหมวดขึ้น `Could not get the news`
- ตอนนี้: สแกนเสร็จ บอร์ดปิดระบบ Bluetooth คืนหน่วยความจำทันที กด Scan ครั้งต่อไปก็เปิดใหม่ให้เอง

✅ **เช็ค:** Settings → About จด Free memory → Bluetooth → Scan → กลับไปดู About ต้องใกล้ค่าเดิม (ไม่ลดลงเกือบร้อย KB) แล้ว Internet → News ต้องโหลดได้
❌ ถ้ายังลดลงมากหรือข่าวยังโหลดไม่ได้: ถ่ายหน้า About ก่อนและหลังสแกนส่งมา

### 6. หน้า About ละเอียดขึ้น + เลขเวอร์ชันเห็นทันที

### 11. ทดสอบก่อนส่ง
- ตัวจำลองบนคอม (รันบน Raspberry Pi 5): **ผ่านทั้งหมด 112 ข้อ** (ของใหม่ 19 ข้อ ทุกข้อขึ้น FAIL บน v11.4 ก่อนแก้ และ PASS บน v11.5)
- ทดสอบเดิม 2 ข้อที่ตั้งใจเปลี่ยน: Tilt Maze/Blocks กดค้าง = ออก (เดิม = หยุด) และแอร์ส่ง 1 ครั้ง (เดิม 2)
- ภาพหน้าจอใหม่ทุกหน้าที่แก้ ทั้งแนวตั้ง แนวนอน ธีมสว่าง และธีมมืด ดูแล้วไม่มีตัวหนังสือล้นหรือถูกตัด

- **ต้องลองบนบอร์ดจริง:** การแฟลชไฟล์ app ที่ `0x10000`, เสียงเตือน, Free memory หลังสแกน Bluetooth, ระยะยิงแอร์ครั้งเดียว

### 1. จอยเลื่อนหน้าได้ทุกหน้า ไม่ติดค้างแล้ว
ปัญหาเดิม (ตามวิดีโอ): หน้าน้ำมันโยกลงแล้วปุ่ม Tech/AI/Robots หายขึ้นไป แล้วเลื่อนกลับไม่ได้ ส่วนหน้า Weather หน้าอ่านข่าว และหน้า About ใช้จอยเลื่อนอ่านไม่ได้เลย
กฎใหม่ของการโยกขึ้น/ลง:
- **ถ้ายังมีเนื้อหาที่ยังไม่เห็น จะเลื่อนเนื้อหาก่อนเสมอ** ถึงสุดแล้วกรอบถึงจะออกไปแถบล่าง (Log / Apps / Settings) หรือขึ้นไปแถบบน
- **หน้าที่ไม่มีปุ่มให้เลือก** (อากาศ, ราคาน้ำมัน, เนื้อข่าว, About): กรอบสีส้มจะไปล้อมพื้นที่อ่านทั้งหมด แปลว่า "ตอนนี้จอยเลื่อนหน้านี้อยู่" โยกลง = เลื่อนลง โยกขึ้น = เลื่อนขึ้น ถ้าเลื่อนไปเจอปุ่ม (เช่น `Back up now`) กรอบจะไปอยู่ที่ปุ่มนั้นเอง
- **อยู่ที่แถบล่างแล้วโยกขึ้น** จะเลื่อนเนื้อหากลับขึ้นไปได้จนถึงบนสุด
- **รายการข่าว:** โยกลงหนึ่งครั้ง = ไปข่าวถัดไป และเลื่อนให้เห็นข่าวนั้นเต็มการ์ด (เดิมบางทีกรอบไปอยู่บนการ์ดที่เห็นแค่ขอบ)
- **แตะจอแล้วกลับมาใช้จอย:** กรอบกลับมาที่ปุ่มเดิม ไม่เด้งไปปุ่มแรก

✅ **เช็ค 1:** Apps → Internet → News → Tech โยกลงเรื่อย ๆ ต้องเลื่อนผ่านราคาน้ำมันลงไปจนสุดข่าว แล้วโยกขึ้นเรื่อย ๆ ต้องกลับมาถึงปุ่ม Tech / AI / Robots ได้
✅ **เช็ค 2:** Weather โยกลง ต้องเห็นกรอบส้มล้อมพื้นที่อากาศ แล้วโยกลงต่อ หน้าต้องเลื่อน
✅ **เช็ค 3:** Settings → About โยกลงจนเห็นปุ่ม `Back up now` กรอบต้องไปอยู่ที่ปุ่มนั้น และลงต่อได้จนถึงบรรทัด Version
❌ ถ้ามีหน้าไหนยังเลื่อนไม่สุดหรือกรอบค้าง ให้ถ่ายวิดีโอหน้านั้นส่งมา

### 3. PIN หน้าเว็บ: ไม่ต้องใส่เมื่อต่อ Wi-Fi ของบอร์ด
- มือถือต่อ Wi-Fi **SomudTick** (Wi-Fi ของบอร์ดเอง ต้องใส่รหัสอยู่แล้ว): **ไม่ถาม PIN**
- มือถือเข้าผ่าน **Wi-Fi บ้าน** (คนอื่นในบ้านเข้าถึงบอร์ดได้): ยังถาม PIN เหมือนเดิม และหน้าเว็บจำ PIN ไว้ 2 ที่ (cookie + ที่เก็บในเบราว์เซอร์) จึงถามน้อยลง
- บนบอร์ด: Settings → Wi-Fi → `PIN (home Wi-Fi only)`
- เบราว์เซอร์ในแอปอื่น (เช่น เปิดลิงก์จากแอป Claude) บางทีลบข้อมูลที่จำไว้ทุกครั้ง ถ้าเข้าผ่าน Wi-Fi บ้านแล้วโดนถามบ่อย ให้เปิดใน Safari แล้ว "เพิ่มไปยังหน้าจอโฮม"

✅ **เช็ค:** ต่อ Wi-Fi SomudTick แล้วเปิด `192.168.4.1` ต้องเข้าได้เลย ไม่มีกล่องถาม PIN

### 4. อัปคลิปจากมือถือ: ไม่ค้างที่ 0% แล้ว
ปัญหาเดิม: หน้าเว็บให้คลิป "กระโดด" ไปทีละภาพ 15 ครั้งต่อวินาทีของคลิป คลิปจาก iPhone (HEVC) กระโดดช้ามาก และถ้าสัญญาณ "กระโดดเสร็จ" หายไปครั้งเดียว หน้าเว็บจะรอตลอดไป
ตอนนี้:
- หน้าเว็บ**เล่นคลิปหนึ่งรอบ (ปิดเสียง) แล้วเก็บภาพไประหว่างเล่น** ใช้เวลาประมาณเท่าความยาวคลิป (คลิป 30 วินาที ≈ 30 วินาที) แล้วค่อยส่งเข้าบอร์ด
- ตัวเลข % ขยับทุกภาพ
- ถ้าคลิปหยุดเล่นกลางทาง (เช่น สลับไปแอปอื่น) จะลองเล่นต่อ ถ้าไม่ได้จะทำส่วนที่เหลือแบบกระโดด แต่รอแต่ละภาพไม่เกิน 3 วินาที ไม่ค้างอีก
- ถ้าแปลงไม่ได้จริง ๆ จะขึ้นข้อความบอก ไม่ค้างเงียบ
- ระหว่างแปลง **อย่าปิดหน้าหรือสลับแอป**

✅ **เช็ค:** รูป/คลิป → เลือกคลิปสั้น ๆ 10–20 วินาที ตัวเลข % ต้องวิ่งขึ้นเรื่อย ๆ จนเสร็จ แล้วเปิดดูที่บอร์ด Apps → Files → videos
❌ ถ้าขึ้นว่าแปลงไม่ได้ ให้ลองเปิดหน้าเว็บใน Safari แทนเบราว์เซอร์ในแอป

### 5. สั่งแอร์: ส่งแรงขึ้น + ส่งซ้ำ
- ขา IO21 ปล่อยกระแสแรงสุดที่ขาทำได้ (ประมาณ 40 mA จากเดิม 20 mA) หลอด IR สว่างขึ้น
- ทุกครั้งที่กดปุ่ม ส่งคำสั่งซ้ำ 2 รอบ ถ้ารอบแรกโดนบังหรือเพี้ยน ยังมีรอบสอง (แอร์รับคำสั่งเดียวกัน 2 ครั้งไม่มีผลเสีย อาจได้ยินเสียงปี๊บ 2 ครั้ง)
- ยังควรหันหลอด IR ไปทางแอร์ และไม่ให้มีอะไรบัง ถ้าอยู่ในกล่อง ให้หลอดโผล่ออกนอกกล่อง

✅ **เช็ค:** หันหลอดไปทางแอร์ ห่าง 1–2 เมตร กดปุ่มในหน้า AC Remote 10 ครั้ง ดูว่าติดกี่ครั้ง
❌ ถ้ายังไม่ค่อยติด ทางที่ได้ผลที่สุดคือเพิ่มทรานซิสเตอร์ NPN (S8050 หรือ 2N2222) ขับหลอด IR ให้กระแสแรงขึ้นหลายเท่า บอกผมแล้วผมจะวาดผังการต่อให้

### 1. จอยสติ๊กคุมได้ทุกหน้า
ใช้นิ้วกับจอยได้พร้อมกัน **ไม่ต้องเปลี่ยนโหมด**
- **โยกครั้งแรก:** กรอบสีส้มโผล่ที่ปุ่มแรกของหน้า (ครั้งแรกแค่ให้กรอบโผล่ ยังไม่เลื่อนและไม่กดอะไร)
- **โยกขึ้น/ลง/ซ้าย/ขวา:** กรอบย้ายไปปุ่มที่อยู่ทางนั้น ถ้ารายการยาว หน้าจะเลื่อนให้เอง โยกขึ้น ลง หรือขวาค้างไว้ กรอบจะวิ่งต่อเนื่อง
- **กดจอยลง:** เหมือนแตะปุ่มนั้น
- **กดจอยค้าง 0.65 วินาที:** เหมือนแตะค้าง เช่น
  - กดค้างบนปุ่ม +1 หรือ − = เปิดแป้นพิมพ์ตัวเลขของกิจกรรมนั้น
  - กดค้างบนไฟล์ = เปิดเมนู Rename / Move / Delete
- **โยกซ้ายค้าง 1 วินาที = Back** (โยกซ้ายเฉย ๆ ครั้งเดียวคือย้ายกรอบไปทางซ้าย 1 ช่อง และโยกซ้ายค้างไว้จะไม่วิ่งต่อเนื่อง ค้างไว้ = ย้อนกลับเท่านั้น)
- **แตะจอ:** กรอบหายไป ใช้นิ้วต่อได้เลย
- **หน้าดูรูป:** ซ้าย/ขวา = รูปก่อนหน้า/ถัดไป, กด = กลับ, กดค้าง = ลบ (มีถามก่อน)
- **กล่อง "แน่ใจไหม" และเมนูหลังดูคลิป:** โยกเลือก แล้วกดยืนยัน **ระหว่างเล่นคลิป:** กดจอย = หยุด

- **กันกดในกระเป๋า:** ตอนจอดับ โยกจอยไม่ทำให้จอติด ต้องกดจอยลง และกดครั้งแรกแค่ปลุกจอ ไม่กดอะไร
- **เกม:** จอยทำหน้าที่ของเกมเหมือนเดิม (Pixel Swim, Sudoku, Sand และเกมใหม่)
- **ปิดได้:** Settings → `Joystick in menus: ON/OFF` ถ้าปิด จอยจะใช้ได้แค่ในเกม ถ้าขึ้น `no stick` แปลว่าบอร์ดหาจอยไม่เจอ (เช็คสาย)

✅ **เช็ค 1:** อยู่หน้า Log โยกจอยลง 1 ครั้ง ต้องเห็นกรอบสีส้มที่ปุ่ม Stats โยกลงอีกครั้ง กรอบต้องย้ายไปที่ปุ่มในช่องกิจกรรม กดจอย ตัวเลขต้องเพิ่ม 1
✅ **เช็ค 2:** โยกลงไปจนถึงแถบ Log / Apps / Settings โยกขวาแล้วกด ต้องเข้าหน้า Apps เลือก Games แล้วโยกซ้ายค้าง 1 วินาที ต้องกลับมาหน้า Apps
✅ **เช็ค 3:** หมุนจอเป็นแนวนอน (Settings → Screen → Wide) โยกจอยไปทางขวาของจอ กรอบต้องไปทางขวาจริง
❌ ถ้าทิศผิด (เช่น โยกขวาแล้วกรอบไปบน) ให้ทำ Settings → **Joystick direction** ใหม่ 1 ครั้ง บอร์ดจะจำว่าตั้งตอนจอหันทางไหน แล้วหมุนทิศให้เองทุกทิศ (ค่าที่ตั้งไว้ก่อน v11.3 ไม่ได้จดว่าตั้งตอนจอหันทางไหน บอร์ดเลยเดาว่าเป็นทิศจอตอนนี้ ถ้าเดาผิดให้ตั้งใหม่ครั้งเดียวพอ)
❌ ถ้ากรอบขยับเองทั้งที่ไม่ได้แตะจอย แปลว่าสาย VRX/VRY หลวม ให้เช็คสาย หรือปิดด้วย `Joystick in menus: OFF`

### 2. เกมใหม่: Tilt Maze (เขาวงกตลูกแก้ว)
Apps → Games → **Tilt Maze**
- โยกจอยเพื่อ "เอียงกระดาน" โยกมากลูกเหล็กยิ่งกลิ้งเร็ว ชนกำแพงแล้วเด้ง พาลูกไปลงหลุมสีเขียว
- เขาวงกตสุ่มใหม่ทุกด่าน แต่ด่านเดิมได้เขาวงกตแบบเดิม จึงเทียบเวลาที่ดีที่สุด (`Best`) ของแต่ละด่านได้ ด่านสูงขึ้นช่องเล็กลงและทางยาวขึ้น

✅ **เช็ค:** เล่นด่าน 1 จนลูกลงหลุมเขียว ต้องขึ้น `Level 1 done!` พร้อมเวลา กดจอยแล้วต้องไปด่าน 2

### 3. เกมใหม่: Blocks (ตัวต่อ)

- **จอย:** ซ้าย/ขวา = เลื่อน (ค้างไว้เลื่อนต่อเนื่อง), ลง = หล่นเร็ว, **ปัดขึ้น = ทิ้งลงทันที**, กด = หมุน, **กดค้าง 1 วินาที = หยุดเกม**
- **ไม่มีจอย:** แตะส่วนซ้าย/ขวาของกระดาน = เลื่อน, แตะตรงกลาง = หมุน, ปัดนิ้วลง = ทิ้ง, แตะนอกกระดาน = หยุด

- คะแนน: 1 แถว = 100, 2 แถว = 300, 3 แถว = 500, 4 แถวพร้อมกัน = 800 (คูณเลเวล) คะแนนสูงสุดเก็บไว้แม้ปิดเครื่อง

✅ **เช็ค:** เริ่มเกม โยกซ้ายขวา ตัวต่อต้องเลื่อนตาม กดจอยต้องหมุน ปัดขึ้นต้องตกลงทันที เต็มแถวแล้วแถวต้องกะพริบแล้วหาย
❌ ถ้าปัดขึ้นแล้วบางทีไม่ตก ให้ปัดให้สุดทางขึ้นตรง ๆ (บอร์ดนับว่าเป็นการปัดขึ้นเมื่อโยกขึ้นเกินครึ่งทางและไม่เฉียงมาก)

แฟลชเหมือนเดิม: ถ้าในบอร์ดเป็น v10 หรือ v11 อยู่แล้ว ไปที่ Settings → About → **Update firmware** แล้วแฟลช `SomudTick_merged.bin` ที่ `0x0` (ดูข้อ 9 ของ v10) ข้อมูลที่บันทึกไว้ไม่หาย
(รูปหน้าจอของ v11.2 อยู่ในโฟลเดอร์ `SomudTick_v11.2`)

ระบบกันกดโดนยังเหมือนเดิมทุกอย่าง: ป้าย Home / Uni ต้องกดค้าง, บันทึกด้วยปุ่ม +1, ตอนจอดับแตะครั้งแรกแค่เปิดจอ, เวลาปิดจอตั้งใน Settings

### 1. นาฬิกา DS3231: รู้เวลาตั้งแต่เปิดเครื่อง
โมดูล DS3231 มีถ่าน CR2032 ของตัวเอง ปิดบอร์ดด้วยสวิตช์แล้วนาฬิกาก็ยังเดินอยู่
- **เปิดเครื่อง:** บอร์ดอ่านเวลาจากโมดูลทันที ไม่มีเครื่องหมาย `~` หน้าเวลา และไม่มีแถบ `Time not set` ไม่ต้องรอ Wi-Fi
- **ได้เวลาจาก Wi-Fi หรือจากมือถือ (หน้าเว็บ):** บอร์ดเขียนเวลาลงโมดูลด้วย โมดูลจึงถูกตั้งให้ตรงอยู่เรื่อย ๆ ส่วนการอัปเดตเวลาผ่าน Wi-Fi ยังทำงานเหมือน v11
- **ถ้าถ่านโมดูลหมด หรือเพิ่งใส่ถ่านใหม่:** บอร์ดไม่เชื่อเวลาในโมดูล กลับไปทำแบบ v11 คือใช้เวลาเดา (`~`) จนกว่าจะได้เวลาจริง แล้วเขียนลงโมดูลให้ใหม่เอง
- **ถ้าไม่ได้ต่อโมดูล:** ทำงานเหมือน v11 ทุกอย่าง
- ปัญหาใน v11 ที่เคยบอกว่าแก้ในโค้ดไม่ได้ (บันทึกตอนเวลายังไม่ตรง แล้วปิดเครื่องก่อนเวลาจะตรง บันทึกจะอยู่ผิดวัน) **หายไปเมื่อต่อโมดูล** เพราะเวลาตรงตั้งแต่เปิดเครื่อง
- บั๊กเล็กที่แก้ด้วย: หลังกด Leave USB drive หรือยกเลิก Update firmware บอร์ดจะรีสตาร์ท เดิมนาฬิกายังตรงอยู่แต่จอขึ้น `~ time not set` ตอนนี้บอร์ดจำได้ว่าเวลาตรงอยู่แล้ว (About จะเขียนว่า `kept`)

**วิธีต่อโมดูล** (⚠️ ถอดแบตและสาย USB ก่อน) ใช้แถวขา 6 ขาของโมดูล:

| ขา DS3231 | ต่อเข้าบอร์ด |
|---|---|
| SDA | **IO16** (ช่อง I2C) |
| SCL | **IO15** (ช่อง I2C) |
| VCC | **3.3V** (ช่อง I2C) ⚠️ ห้ามต่อ 5V |
| GND | **GND** (ช่อง I2C) |
| 32K, SQW | ไม่ต้องต่อ |

- ใส่ถ่าน CR2032 ด้านหลังโมดูล ให้ด้าน **+ หงายขึ้น**
- ⚠️ **ห้ามต่อ 5V เด็ดขาด** โมดูลนี้มีวงจรชาร์จถ่าน ถ้าใช้ 5V จะชาร์จเข้าถ่าน CR2032 ซึ่งชาร์จไม่ได้ ถ่านอาจบวม ใช้ 3.3V ปลอดภัย
- ตอนนี้ขา 3.3V และ GND ของช่อง I2C ต้องแยกไป 3 อุปกรณ์ (จอย, KY-005, DS3231) ให้บัดกรีรวมสายแล้วหุ้มท่อหด (ดูแผนเดินสายในโฟลเดอร์ `SomudTick_case`)

✅ **เช็ค 1:** ต่อโมดูลแล้วเปิดเครื่อง ไปที่ Settings → About บรรทัด `Clock module` ต้องขึ้น `OK` หรือ `time lost: join Wi-Fi` (ครั้งแรกโมดูลยังไม่เคยถูกตั้งเวลา)
❌ ถ้าขึ้น `not found` ให้ปิดเครื่อง แล้วเช็คสาย SDA → IO16, SCL → IO15, VCC → 3.3V, GND → GND (สาย SDA กับ SCL สลับกันบ่อยที่สุด)
❌ ถ้าต่อโมดูลแล้วจอสัมผัสไม่ตอบสนอง แปลว่าสาย SDA/SCL ลัดกันหรือสลับกัน ให้ปิดเครื่องแล้วเช็คสาย

✅ **เช็ค 2:** ต่อ Wi-Fi ให้บอร์ดได้เวลาจริง (หรือเปิดหน้าเว็บจากมือถือ) บรรทัด `Clock module` ต้องเปลี่ยนเป็น `OK`
แล้วปิดเครื่องด้วยสวิตช์ ปิด Wi-Fi ที่บ้านหรือ Hotspot มือถือ (ให้บอร์ดต่อเน็ตไม่ได้) รอ 1 นาทีแล้วเปิดเครื่องใหม่
หัวจอต้องขึ้นเวลาตรง**ไม่มี** `~` และ About บรรทัด `Time` ต้องลงท้ายด้วย `(module)`
❌ ถ้าเวลายังมี `~` ให้ดูบรรทัด `Clock module` ถ้าขึ้น `time lost` แปลว่าถ่าน CR2032 หมดหรือใส่กลับด้าน

### 2. ประหยัดแบตตอนจอดับ
ตอนจอดับ บอร์ดยังทำงานต่อ (เตือนตามเวลา, หน้าเว็บ, นาฬิกา) แต่ใช้ไฟน้อยลง:
- ชิปจอหลับ ซีพียูเดินช้าลงจาก 240 เหลือ 80 MHz และเช็คจอสัมผัส 25 ครั้งต่อวินาทีแทน 200 ครั้ง
- จอดับเกิน 10 นาทีและไม่มีมือถือต่อ Hotspot `SomudTick` อยู่ Hotspot จะพักด้วย **แตะจอเมื่อไหร่ Hotspot กลับมาเอง** ใน Settings ยังขึ้น ON ตามเดิม
- แตะจอแล้วทุกอย่างกลับมาเร็วเต็มที่ทันที ส่วนตอนเปิดโหมด USB drive จะไม่ลดความเร็ว

✅ **เช็ค:** ปล่อยให้จอดับเกิน 10 นาที แล้วดูรายชื่อ Wi-Fi ในมือถือ ต้องไม่เห็น `SomudTick` แตะจอ 1 ครั้ง รอ 5 วินาที ต้องเห็น `SomudTick` กลับมา
❌ ถ้าเปิดหน้าเว็บไม่ได้หลังเปิดจอ ให้รอสักครู่ให้มือถือต่อ Hotspot ใหม่ หรือกดต่อ `SomudTick` เอง

### 3. สำรองข้อมูลลงการ์ด SD ทุกสัปดาห์
- ทุก 7 วัน บอร์ดคัดลอกบันทึกทั้งหมดลงการ์ดเป็นไฟล์ `SomudTick/backup/logs_2026-09-25.csv` (คอลัมน์เดียวกับไฟล์ส่งออกจากหน้าเว็บ เปิดใน Excel ได้) เก็บไว้ 8 ไฟล์ล่าสุด ไฟล์เก่ากว่านั้นลบเอง
- ทำตอนไม่มีใครใช้เครื่อง (จอดับ หรือไม่ได้แตะเกิน 2 นาที) จึงไม่ทำให้เครื่องช้าตอนใช้งาน ต้องมีการ์ด SD และเวลาต้องตรง
- สั่งสำรองเองได้ที่ Settings → About → ปุ่ม **Back up now** บรรทัด `Backup to SD` บอกวันที่สำรองล่าสุด

✅ **เช็ค:** ใส่การ์ด SD แล้วกด Settings → About → **Back up now** บรรทัด `Backup to SD` ต้องเปลี่ยนเป็นวันที่วันนี้ แล้วเปิด Apps → Files → `SomudTick` → `backup` ต้องเห็นไฟล์ (หน้า Files แสดงเฉพาะรูปกับคลิป ดูไฟล์ .csv ให้ใช้โหมด USB drive กับคอม หรือถอดการ์ดไปเสียบคอม)
❌ ถ้าขึ้น `no SD card` ให้เสียบการ์ดใหม่ / `set the time first` ให้ต่อ Wi-Fi ก่อน / `card full?` การ์ดเต็ม ให้ลบไฟล์ออกบ้าง

### 4. หน้า About บอกอาการเครื่อง
| บรรทัด | บอกอะไร |
|---|---|
| `Time 14:05 (module)` | เวลาได้มาจากไหน: `module` = DS3231, `Wi-Fi` = อินเทอร์เน็ต, `phone` = มือถือ, `kept` = จำไว้ตอนรีสตาร์ท, `not set` = ยังไม่รู้เวลา |
| `Clock module` | `OK` / `not found` (ไม่ได้ต่อ) / `time lost: join Wi-Fi` (ถ่านหมดหรือยังไม่เคยตั้ง) |
| `Backup to SD` | วันที่สำรองล่าสุด / `never` / ตัวแดง = สำรองไม่ได้ พร้อมบอกเหตุผล |
| `Last start` | เปิดเครื่องครั้งล่าสุดเพราะอะไร: `power on` เปิดสวิตช์, `restart` บอร์ดสั่งเอง, `RESET button` กดปุ่ม RESET, ตัวแดง = `crash` (โปรแกรมพัง), `froze (watchdog)` (ค้างแล้วรีเซ็ตเอง), `battery too low` (ไฟตก) |
| `Free memory` | หน่วยความจำที่เหลือ ตัวแดง = เคยเหลือน้อยกว่า 30 KB |

ถ้าวันไหนเครื่องค้างหรือรีสตาร์ทเอง ให้ถ่ายรูปหน้า About ส่งมาให้ดู จะรู้สาเหตุเร็วขึ้น

### 5. จอลื่นขึ้น
- หน้า Log เดิมวาดจอใหม่ทุก 1 วินาที ทั้งที่นาฬิกาแสดงแค่นาที ตอนนี้วาดเมื่อนาทีเปลี่ยน และทุก 15 วินาทีสำหรับคำว่า `5m ago` ซีพียูว่างขึ้น แตะแล้วตอบสนองไวขึ้น
- หน้า Stats เปิดครั้งที่สองขึ้นทันที ไม่ต้องอ่านไฟล์ทุกวันใหม่ จะนับใหม่เฉพาะตอนมีบันทึกเปลี่ยน
- พิมพ์ตัวเลขเอง เช่น Water 5 ครั้ง เดิมเขียนแฟลช 10 ครั้ง ตอนนี้เขียนครั้งเดียว
- ไฟ LED ไม่ต้องคำนวณเรื่องเตือนทุก 5 มิลลิวินาทีแล้ว คิดวินาทีละครั้ง

### 6. บั๊กที่แก้ (ตรวจโค้ดทุกไฟล์ใหม่ รวมทั้งบั๊กเล็ก ๆ)
1. เลื่อนนาฬิกาถอยหลังแล้วเตือน `Time for ...` ผิด (บันทึกดูเหมือนอยู่ในอนาคต)
2. ไฟดับตรงจังหวะที่บอร์ดกำลังเขียนไฟล์บันทึกของวันนั้นใหม่ (ตอนกด −) บันทึกทั้งวันอาจหาย ตอนนี้เปิดเครื่องครั้งถัดไปบอร์ดซ่อมให้เอง
3. กด − ยกเลิกบันทึกเมื่อคืนที่กดตอนเวลายังไม่ตรง พอเวลาตรงบันทึกนั้นกลับมาเอง
4. บันทึกที่ถูกย้ายวันตอนเวลาตรง ไปต่อท้ายไฟล์ ไม่เรียงตามเวลา
5. หน้า Log: ถ้ามีเตือนค้างอยู่ แถบ `Time not set` หรือ `Log space FULL` จะไม่ขึ้น
6. หน้าเว็บ กด "บันทึก Wi-Fi" แล้วบอร์ดไปต่อ Wi-Fi ทั้งที่ปิด Internet Wi-Fi ไว้ และถ้าส่งข้อมูลมาไม่ครบ ชื่อ Wi-Fi ที่บันทึกไว้จะหาย
7. สลับหมวดข่าวเร็ว ๆ ตอนกำลังโหลด หมวดที่สองบางทีไม่โหลดจนกว่าจะกด Reload
8. ส่งรูปจากมือถือตอนเปิดเมนูไฟล์ (Rename / Move / Delete) ค้างไว้ เมนูอาจไปทำกับไฟล์อื่น หรือเครื่องค้าง
9. ส่งรูปจากมือถือตอนดูรูปอยู่ แล้วกด Delete อาจลบรูปอื่นที่ไม่ได้เปิดดู
10. Put back ไฟล์จากถังขยะ ไปโฟลเดอร์ที่ถูกลบไปแล้ว ขึ้น `Could not do it` ตอนนี้สร้างโฟลเดอร์ให้ใหม่
11. โฟลเดอร์ที่มีรูปเกิน 300 ไฟล์ ไฟล์ที่เกินหายไปเฉย ๆ ตอนนี้ท้ายรายการเขียนว่า `First 300 files shown`
12. Garden: ไม่เปิดสวนนานเกิน 30 วัน สถิติวันติดกัน (streak) ยังนับต่อ ทั้งที่มีวันที่ขาดไป
13. เปิดเครื่องทิ้งไว้เกิน 49 วัน ไฟ LED กับไฮไลต์ตอนกด +1 จะค้าง (ตัวนับเวลาของชิปวนกลับ)
14. หลังรีสตาร์ทจาก USB drive นาฬิกาตรงแต่จอขึ้น `~` (อยู่ในข้อ 1 ข้างบน)
15. หน้า About ข้อความ `Restarts ready for the flasher page` ยาวจนถูกตัด เปลี่ยนเป็น `For the web flasher`

✅ **เช็คหลังแฟลช:** กด +1 และ − ในหน้า Log ได้ปกติ, Stats เปิดได้และตัวเลขตรงกับ v11, Settings → About มีบรรทัดใหม่ `Clock module`, `Backup to SD`, `Last start`, `Free memory` และ `Version v11.2`

## ของใหม่ใน v11 (แก้บั๊ก)

v11 เป็นรอบแก้บั๊กอย่างเดียว ไม่มีฟีเจอร์ใหม่ใหญ่ ๆ หน้าตาเหมือน v10 เกือบทั้งหมด
แฟลชเหมือนเดิม: ถ้าในบอร์ดเป็น v10 อยู่แล้ว ใช้ Settings → About → **Update firmware** ก่อน (ดูข้อ 9 ของ v10 ด้านล่าง) ข้อมูลที่บันทึกไว้ไม่หาย
ดูหน้าตาได้ในรูป `preview_v11_tall.png` (จอแนวตั้ง) และ `preview_v11_wide.png` (จอแนวนอน)

ระบบกันกดโดนยังเหมือน v10 ทุกอย่าง: ป้าย Home / Uni ต้องกดค้าง, บันทึกด้วยปุ่ม +1, ตอนจอดับแตะครั้งแรกแค่เปิดจอ, เวลาปิดจอตั้งใน Settings

### 1. แบตเตอรี่ % ตรงขึ้น
- เดิมคิดเป็นเส้นตรง แบตลิเธียมจริงลดช้าตอนกลาง ๆ แล้วลดเร็วตอนใกล้หมด จอจึงเคยบอก 30% ทั้งที่ใกล้ดับแล้ว ตอนนี้ใช้ตารางแรงดันของแบตลิเธียม
- ตอนเสียบชาร์จ ตัวเลขจะสูงกว่าจริงนิดหน่อย (บอร์ดไม่มีขาบอกว่ากำลังชาร์จ บอร์ดเลยรู้ไม่ได้ว่าชาร์จอยู่)
  ✅ เช็ค: ดูที่ Settings → About → Battery ตัวเลข V กับ % ต้องเป็นไปตามนี้โดยประมาณ: 4.20 V = 100%, 4.00 V = 78%, 3.80 V = 45%, 3.70 V = 25%, 3.60 V = 8%

### 2. แถบแจ้งเตือนในหน้า Log
แถบด้านล่างหน้า Log (ตำแหน่งเดียวกับแถบ `Time for Water`) แตะแล้วพาไปหน้าที่แก้ได้:
- `Time not set: tap here` = เวลาในบอร์ดยังไม่ตรง (ปิดเครื่องด้วยสวิตช์แล้วเปิดใหม่โดยไม่มีเน็ต นาฬิกาจะหาย) แตะ = ไป Settings → Wi-Fi ต่อ Wi-Fi หรือเปิดหน้าเว็บจากมือถือ เวลาจะตรงเอง และบันทึกที่กดไปตอนเวลาไม่ตรงจะถูกย้ายไปวันที่ถูก (ตั้งแต่ v10)
- `Log space almost full` (สีแดง) = ที่เก็บบันทึกใช้ไปเกิน 90% / `Log space FULL: logs not saved` = เต็มแล้ว บันทึกไม่ได้ แตะ = ไปหน้า About
- หน้า About บรรทัด Log space จะเป็น**ตัวสีแดง**เมื่อเกิน 90% (v10 เขียนใน README ไว้ว่าจะเตือน แต่จริง ๆ ไม่เตือน แก้แล้ว)
  ✅ เช็ค: ปิด Internet Wi-Fi แล้วปิดเปิดเครื่องด้วยสวิตช์ หน้า Log ต้องมีแถบ `Time not set: tap here` แตะแล้วต้องไปหน้า Wi-Fi
  ⚠️ (v11.2: ต่อโมดูล DS3231 แล้วปัญหานี้หายไป) ข้อจำกัดที่แก้ไม่ได้ในโค้ด: บอร์ดนี้ไม่มีแบตสำรองสำหรับนาฬิกา ถ้ากดบันทึกตอนเวลาไม่ตรง แล้ว**ปิดเครื่องก่อนเวลาจะตรง** บันทึกพวกนั้นจะยังอยู่ผิดวัน (บอร์ดไม่รู้ว่าปิดไปนานเท่าไร) วิธีเลี่ยง: เปิดเครื่องแล้วให้ต่อเน็ตหรือเปิดหน้าเว็บก่อนเริ่มกดบันทึก

### 3. กด − ยกเลิกของเมื่อคืนได้
- เดิมกด − ได้แค่ของวันนี้ ถ้ากด +1 ตอน 23:50 แล้วเพิ่งเห็นว่ากดผิดตอน 00:10 จะยกเลิกไม่ได้ ตอนนี้ยกเลิกครั้งล่าสุดได้ ถ้าเพิ่งผ่านมาไม่เกิน 6 ชั่วโมง (ปุ่ม − จะกดได้)
  ✅ เช็ค (ถ้ามีโอกาส): กด +1 ก่อนเที่ยงคืน แล้วหลังเที่ยงคืนกด − ของกิจกรรมนั้น บันทึกเมื่อวานต้องหายไป 1 ครั้ง (ดูใน Stats → Days)

### 4. ลบกิจกรรมแล้วเพิ่มใหม่ชื่อเดิม ประวัติกลับมา
- เดิมลบกิจกรรมในหน้าเว็บ แล้วเพิ่มใหม่ชื่อเดิม บอร์ดจะมองเป็นกิจกรรมใหม่ ประวัติเก่าหาย ตอนนี้ถ้าชื่อตรงกับกิจกรรมที่เคยมี (ตัวพิมพ์เล็ก / ใหญ่ไม่มีผล) จะได้ประวัติเดิมกลับมา รวมถึง Meal และ Snack ที่ลบไปใน v10
- ไฟล์ CSV ที่ส่งออก กิจกรรมที่ลบไปแล้วจะขึ้นชื่อเดิมตามด้วย `(ลบแล้ว)` แทนที่จะเป็น `(ลบแล้ว)` เฉย ๆ
  ✅ เช็ค: หน้าเว็บ แท็บ "กิจกรรม" → เพิ่มกิจกรรม ชื่อ `Meal` → บันทึกลงบอร์ด → Log → Stats → Days ของ Meal ต้องเห็นกราฟของวันก่อน ๆ

### 5. ข่าวกับอากาศ และ Bluetooth ไม่ทำให้จอค้างแล้ว
- เดิมกด News / Weather / Reload แล้วจอค้างได้ถึงประมาณ 20 วินาที กดอะไรไม่ได้ และหน้าเว็บในมือถือก็ค้างด้วย ตอนนี้บอร์ดโหลดอยู่เบื้องหลัง ระหว่างนั้นขึ้น `Loading...` แต่ยังกด Back เปลี่ยนแท็บ หรือไปหน้าอื่นได้ โหลดเสร็จแล้วข่าวขึ้นเอง
- Bluetooth → Scan เดิมจอค้าง 5 วินาที ตอนนี้ขึ้น `Scanning... 4 s` นับถอยหลัง จอยังใช้ได้
  ✅ เช็ค: Apps → Internet → News → กด AI แล้วรีบกด Tech ทันที ต้องกดได้ ไม่ค้าง

### 6. เกม
- **Sudoku:** เดิมบันทึกกระดานลงหน่วยความจำทุกครั้งที่ใส่เลข (ทำให้หน่วยความจำสึกเร็ว) ตอนนี้บันทึกทุก 30 วินาที ตอนกด Back และตอนจอดับ ถ้าปิดสวิตช์กลางเกม จะหายไม่เกิน 30 วินาทีล่าสุด

- **Garden:** เปิดครั้งแรกตอนเวลาในบอร์ดยังไม่ตรง จะขึ้น `Set the time to grow it` (เดิมขึ้นเป็นเมล็ดเฉย ๆ เหมือนไม่มีประวัติ) / คำว่า `Tap a fruit!` ขึ้นเฉพาะตอนที่มีผลไม้ให้เห็นบนต้นจริง ๆ

### 7. อื่น ๆ
- **Goals ในหน้า Log นับเหมือน Garden:** เป้าแบบ max (เช่น Smoke ไม่เกิน 5) นับว่าทำได้เมื่อวันนั้นบันทึกอะไรไปแล้วอย่างน้อย 1 อย่าง เดิมหน้า Log นับตั้งแต่ตื่นนอนยังไม่ได้กดอะไร ทำให้ตัวเลขไม่ตรงกับ Garden
- **กราฟ Stats → Days:** ตัวเลขบนแท่งไม่ทับเส้นประเป้าแล้ว
- **Update firmware ถามก่อน:** เดิมแตะพลาดตอนเลื่อนหน้า About บอร์ดจะเข้าโหมดแฟลชทันที (จอดับเหมือนเครื่องเสีย) ตอนนี้ถาม `Update firmware?` ก่อน กด **Restart** ถึงจะเข้าโหมด
- **About → SD card:** ไม่มีการ์ดขึ้น `no card` (เดิมขึ้น `not checked`)
- **PIN หน้าเว็บ:** สุ่มหลังเปิด Wi-Fi แล้ว (ตอนนั้นชิปสุ่มเลขได้จริง เดิมสุ่มก่อน อาจเดาได้ง่ายกว่า) PIN เดิมที่ได้จาก v10 ยังใช้ได้ ถ้าอยากได้ PIN ใหม่ กด **New** ที่ Settings → Wi-Fi
- **ถังขยะผ่านหน้าเว็บ:** ไฟล์ในถังขยะออกได้ทางปุ่ม "กู้คืน" เท่านั้น (เดิมมีช่องย้ายออกทางอื่นแล้วรายการในถังขยะไม่อัปเดต)
- **คำเตือนชื่อไฟล์:** บอกตรงกับที่ใช้ได้จริง: A-Z 0-9 ช่องว่าง - _ . ( )

### 1. ที่เก็บบันทึกใหญ่ขึ้น (จากประมาณ 7 เดือน เป็นหลายปี)
- เดิมบันทึกทั้งหมดอยู่ในพื้นที่เล็ก 896 KB ถ้ากดวันละ 20 ครั้งขึ้นไป จะเต็มในประมาณ 7 เดือน และพอเต็มแล้ว**บันทึกจะหายเงียบ ๆ**
- v10 เพิ่มพื้นที่ใหม่ **12 MB** เฉพาะสำหรับบันทึก (ใช้ส่วนของหน่วยความจำที่เดิมว่างเฉย ๆ) พื้นที่เดิมไม่ถูกแตะ
- **เปิดเครื่องครั้งแรกหลังแฟลช:** จอจะขึ้น `Moving your logs...` สักครู่ บอร์ดกำลังย้ายบันทึกเก่าไปพื้นที่ใหม่ (ย้ายทีละไฟล์ ลบของเก่าเฉพาะไฟล์ที่คัดลอกครบแล้ว)
- ยอดรวมทั้งหมด (Total ในหน้า Stats) เก็บแยกไว้ในไฟล์เล็ก ๆ ไฟล์เดียว หน้า Stats จึงเปิดเร็วเท่าเดิมแม้ใช้ไปหลายปี
- Settings → About มีบรรทัด **Log space** บอกว่าใช้พื้นที่ไปกี่ % ถ้าเกิน 90% ตัวเลขจะเป็นตัวหนา
  ✅ เช็ค: หลังแฟลช ตัวเลขวันนี้ในหน้า Log และกราฟในหน้า Stats ต้องยังอยู่ครบเหมือนก่อนแฟลช / Settings → About ต้องมีบรรทัด `Log space  0% used`
  ❌ ถ้า About ขึ้น `(old)` ต่อท้าย แปลว่าบอร์ดหาพื้นที่ใหม่ไม่เจอ (บันทึกยังใช้ที่เดิม ไม่หาย) บอกผมได้เลย

### 2. หน้า Stats ย้ายไปอยู่ในหน้า Log / แถบล่างเหลือ 3 ปุ่ม
- แถบล่างเหลือ **Log / Apps / Settings**
- หน้า Log บรรทัดบนสุดมีปุ่มดำ **Stats** (มีรูปกราฟเล็ก ๆ) มุมขวา กดแล้วเปิดหน้า Stats เต็มหน้าเหมือนเดิม (All / Days / Hours) ปุ่ม **Back** มุมซ้ายบน = กลับหน้า Log
- บรรทัดบนสุดเปลี่ยนจาก `Goals done 2 / 4` เป็น `Goals 2 / 4` (สั้นลงให้มีที่วางปุ่ม)
  ✅ เช็ค: Log → Stats → ต้องเห็นปุ่ม Back, All, Days, Hours ครบ ไม่ถูกตัด / กด Back ต้องกลับหน้า Log

### 3. เอา Meal (กินข้าว) และ Snack (ขนม) ออก
- ลบออกจากรายการครั้งเดียวตอนเปิดเครื่องครั้งแรก บันทึกเก่ายังอยู่ในไฟล์ และยังส่งออกเป็น CSV ได้ (ชื่อจะขึ้นว่า `(ลบแล้ว)`)

  ✅ เช็ค: หน้า Log เหลือ Water, Toilet, Fuel, Smoke, Rest (รวมกิจกรรมที่คุณเพิ่มเอง)

### 4. แก้บั๊ก
- **ใส่ตัวเลขเองแล้วนับผิด:** เดิมกดค้างที่ Water แล้วพิมพ์ 3 ตัวเลขเพิ่มแค่ 1 ตอนนี้เพิ่ม 3 จริง (กิจกรรมแบบนับครั้ง = พิมพ์กี่ครั้งก็นับเท่านั้น สูงสุด 50 / กิจกรรมที่มีหน่วย เช่น Fuel = พิมพ์เป็นจำนวนเงินเหมือนเดิม) ปุ่ม "ใส่ค่า" ในหน้าเว็บก็แก้แล้ว
  ✅ เช็ค: กดค้างที่ Water → พิมพ์ 3 → Save ตัวเลขต้องเพิ่ม 3
- **เวลาย้อนหลัง:** เดิมถ้าบอร์ดเปิดเครื่องตอนไม่มีเน็ต (เช่น แบตหมดข้ามคืน) บอร์ดจะใช้เวลาเก่าที่จำไว้ บันทึกตอนเช้าจึงไปอยู่ในวันของเมื่อวาน ตอนนี้พอได้เวลาจริง (ต่อ Wi-Fi หรือเปิดหน้าเว็บจากมือถือ) บอร์ดจะ**ย้ายบันทึกพวกนั้นไปวันและเวลาที่ถูกให้เอง**
  ✅ เช็ค: ปิด Internet Wi-Fi → ถอดแบต/USB แล้วเปิดใหม่ → แถบบนขึ้น `~` หน้าเวลา และ `time?` → กด +1 ที่ Water → เปิดหน้าเว็บจากมือถือ (บอร์ดตั้งเวลาตามมือถือ) → Water วันนี้ต้องนับครั้งที่เพิ่งกดด้วย
- **การเตือนไม่ดึงจอแล้ว:** เดิมพอถึงเวลาเตือน บอร์ดจะเด้งไปหน้า Log ทันที ถ้ากำลังพิมพ์รหัส Wi-Fi อยู่ก็หายหมด ตอนนี้จะขึ้น**แถบสีดำด้านล่าง** `Time for Water  >` บนหน้าที่เปิดอยู่ พร้อมไฟ LED กะพริบ (ถ้าจอดับอยู่จะเปิดจอ) **แตะแถบ = ไปหน้า Log** / บันทึกกิจกรรมนั้นแล้วแถบหายเอง
  ✅ เช็ค: ตั้งเตือน Water เป็น 1 นาทีในหน้าเว็บ รอ 1 นาทีในหน้า Apps ต้องขึ้นแถบ `Time for Water` ด้านล่าง และยังอยู่หน้า Apps
- **ปุ่ม BOOT:** เดิมกดสั้นแล้วบันทึกกิจกรรมแรก (Water) ได้จากทุกหน้าโดยไม่รู้ตัว ตอนนี้บันทึกเฉพาะตอนอยู่หน้า Log หน้าอื่นแค่ปลุกจอ
- **ป้าย Home / Uni บนแถบหัว:** เดิมแตะนิดเดียวก็สลับ (โดนในกระเป๋าง่าย) ตอนนี้ต้อง**กดค้าง** ถึงจะสลับ (ไฟ LED กะพริบขาว 1 ครั้ง) หรือสลับในหน้า Settings เหมือนเดิม
- **จอไม่ดับในบางหน้า:** เกม Pixel Swim ตอนหยุดชั่วคราว / หน้าดูรูป / กล่องถาม "Move to Trash?" เดิมจอติดสว่างไปเรื่อย ๆ ตอนนี้ถ้าไม่แตะนานเท่าเวลาปิดจอใน Settings จะกลับหน้าก่อนหน้าแล้วจอดับตามปกติ (ตอนกำลังเล่น Pixel Swim จอยังติดเหมือนเดิม)
- **ส่งรูปจากมือถือชื่อซ้ำ:** เดิมเขียนทับรูปเดิม ตอนนี้ตั้งชื่อใหม่ให้ เช่น `cat (2).jpg`
- **กด − (ยกเลิก):** บอร์ดเขียนไฟล์ของวันนี้แบบปลอดภัยขึ้น (เขียนไฟล์ใหม่ให้เสร็จก่อนแล้วค่อยสลับ) ไฟดับตอนนั้นก็ไม่เสียบันทึกทั้งวัน

### 6. ปรับหน้าตา
- **ปุ่ม Back ในเกม:** Sand และ Sudoku ใช้ปุ่ม Back ขนาดและตำแหน่งเดียวกับทุกหน้า ตัวหนังสือไม่ตก ไม่เบียดปุ่มข้าง ๆ
- **ตัวเลข Sudoku:** เปลี่ยนเป็นฟอนต์ธรรมดา เรียบ ๆ (เดิมตัวหนาแล้วเลข 6 8 9 ดูเป็นก้อน) เลขโจทย์สีดำ เลขที่ใส่เองสีฟ้า
- **เกม Sand:** สีเข้ากับหน้าอื่นแล้ว ใช้ธีมสว่าง / มืดตาม Settings (พื้นขาวหรือดำ แถบบนเหมือนแอปอื่น) สีทรายบนธีมสว่างเข้มขึ้นนิดหน่อยให้เห็นชัดบนพื้นขาว
- **ชื่อน้ำมันเป็นภาษาอังกฤษ:** `ดีเซล B20` → `B20 Diesel` / `ไฮดีเซล` → `Hi Diesel` / `ไฮ พรีเมียม ดีเซล พลัส` → `Hi Premium Diesel Plus` / `แก๊สโซฮอล์ 95` → `95 Gasohol` (ถ้าบางจากเพิ่มชื่อใหม่ที่บอร์ดไม่รู้จัก คำนั้นจะยังเป็นภาษาไทย)

### 7. PIN หน้าเว็บ
- หน้าเว็บในมือถือต้องใส่ **PIN 4 หลัก** ก่อนใช้ (ถามครั้งเดียว มือถือจำไว้) กันคนอื่นที่อยู่ Wi-Fi เดียวกัน (เช่น Wi-Fi มหาลัย) เข้ามาดูบันทึก ลบกิจกรรม หรือลบไฟล์ในการ์ด
- ดู PIN ได้ที่บอร์ด: **Settings → Wi-Fi → PIN (home Wi-Fi only)** (ตั้งแต่ v11.4 ถามเฉพาะตอนเข้าผ่าน Wi-Fi บ้าน) ปุ่ม **New** = สุ่ม PIN ใหม่ (มือถือที่จำ PIN เก่าจะถูกถามใหม่)
- ใส่ผิด 5 ครั้ง = ล็อก 1 นาที
  ✅ เช็ค: เปิดหน้าเว็บ ต้องมีกล่องถาม PIN → ใส่เลขตามที่บอร์ดโชว์ → หน้าเว็บใช้ได้ตามปกติ / ปิดแล้วเปิดใหม่ต้องไม่ถามอีก
  ❌ ถ้าใส่ถูกแล้วยังถามซ้ำ ให้ลองเปิดด้วย Chrome หรือ Safari ปกติ (โหมดไม่ระบุตัวตนจำ PIN ไม่ได้)

### 8. USB drive: จัดการไฟล์ในการ์ด SD จากคอมผ่านสาย USB
- **Apps → Files → แถวล่างสุด `USB drive  PC >`** (อยู่ในหน้าแรกของ Files)
- เสียบสาย USB จากบอร์ดเข้าคอม (สายต้องส่งข้อมูลได้ ไม่ใช่สายชาร์จอย่างเดียว) คอมจะเห็นการ์ดเป็นไดรฟ์ใหม่ใน This PC เหมือนแฟลชไดรฟ์ ก๊อป ลบ เปลี่ยนชื่อไฟล์อะไรก็ได้
- ก่อนเริ่ม บอร์ดจะ**ก๊อปบันทึกทั้งหมดเป็นไฟล์ `SomudTick/logs.csv` ลงการ์ด**ให้ด้วย เปิดใน Excel ได้เลย
- ระหว่างนี้บอร์ด**จะไม่แตะการ์ดเลย** (ถ้าคอมกับบอร์ดเขียนพร้อมกันไฟล์จะพัง) แอป Files และการส่งรูปจากมือถือจะใช้ไม่ได้จนกว่าจะออก
- หน้าจอบอกสถานะ `Working: 12.0 MB` = กำลังรับส่งข้อมูล (ตัวเลข = ข้อมูลที่รับส่งไปแล้ว)
- **เสร็จแล้ว: กด Eject ไดรฟ์นั้นในคอมก่อน** (คลิกขวาที่ไดรฟ์ → Eject) บอร์ดจะขึ้น `Ejected. Restarting...` แล้วรีสตาร์ตเอง กลับมาใช้การ์ดได้ตามปกติ
- ถ้ากด **Leave USB drive** บนบอร์ดโดยยังไม่ Eject บอร์ดจะถาม `Ejected it first?` ก่อน
- ความเร็วประมาณ 0.5–1 MB/s (USB ของชิปนี้เป็นแบบความเร็วต่ำ ช้ากว่าเครื่องอ่านการ์ด) คลิป 5 MB ใช้ประมาณ 5–10 วินาที
- ⚠️ **ห้ามฟอร์แมตการ์ดจากคอมเป็น exFAT** บอร์ดจะอ่านไม่ได้ ต้องเป็น FAT32
  ✅ เช็ค 1: Files → USB drive → คอมต้องเด้งไดรฟ์ใหม่ขึ้นมา มีโฟลเดอร์ photos, videos และ SomudTick (ข้างในมี logs.csv)
  ✅ เช็ค 2: ลากรูปจากคอมไปใส่โฟลเดอร์ photos → Eject → บอร์ดรีสตาร์ต → Apps → Files → photos ต้องเจอรูปนั้น
  ❌ ถ้าคอมไม่เห็นไดรฟ์: เปลี่ยนสาย USB (สายชาร์จบางเส้นไม่มีสายข้อมูล) หรือลองช่อง USB อื่นของคอม
  ℹ️ ส่วนนี้ทดสอบในตัวจำลองบนคอมไม่ได้ เพราะต้องมีสาย USB จริง ถ้าลองแล้วไม่ได้ บอกผมพร้อมอาการ

### 9. แฟลชครั้งต่อไป (หลังจากมี v10 ในบอร์ดแล้ว)
v10 เปลี่ยนการตั้งค่า USB ของบอร์ด (เพื่อทำ USB drive) หน้าเว็บแฟลชจึงอาจสั่งบอร์ดเข้าโหมดแฟลชเองไม่ได้ ใช้วิธีใดวิธีหนึ่ง:
- **วิธีง่าย:** Settings → About → กด **Update firmware** จอขึ้น `Update mode` แล้วดับ แปลว่าพร้อมแฟลช → ทำขั้นที่ 1 ตามปกติ (กด Connect → Program) เสร็จแล้วกดปุ่ม RESET
- **วิธีสำรอง (ใช้ได้เสมอ แม้บอร์ดเปิดไม่ขึ้น):** กดปุ่ม **BOOT ค้าง** → กดปุ่ม **RESET** แล้วปล่อย → ปล่อย BOOT → จอดับ = พร้อมแฟลช → ทำขั้นที่ 1 → เสร็จแล้วกด RESET
- ถ้าเข้าโหมดแฟลชแล้วเปลี่ยนใจ กดปุ่ม RESET บอร์ดจะกลับมาเป็น SomudTick ตามเดิม
- ตอนกด Connect ชื่อพอร์ตอาจเป็น `USB JTAG/serial debug unit` เลือกอันนั้น
> การแฟลช v10 ครั้งแรก (จาก v7, v8 หรือ v9) ยังทำเหมือนเดิม ไม่ต้องกดปุ่ม

### 2. เกมใหม่: Sand & Water (โปรยทรายกับน้ำ)
เกมเล่นเพลิน ๆ ไม่มีคะแนน ไม่มีเวลา ไม่มีแพ้
- **ลากนิ้วบนจอ** = โปรยทราย ทรายจะกองเป็นภูเขา น้ำจะไหลลงแล้วแผ่ออกจนเรียบ ทรายหนักกว่าน้ำ จึงจมลงไปในน้ำได้
- แถบด้านบน (จากซ้ายไปขวา):
  - **Back** = กลับหน้า Games
  - **วงกลมสี** = ทราย **แตะซ้ำอีกครั้ง = เปลี่ยนสี** มี 8 สี และสีสุดท้ายเป็น**สีรุ้ง** (วงกลมหลายสี) สีจะเปลี่ยนไปเรื่อย ๆ ระหว่างโปรย
  - **หยดน้ำ** = น้ำ
  - **ก้อนสีเทา** = หิน วาดเป็นเส้นได้ หินไม่ตก ใช้ทำชั้นวางหรือกำแพงกั้นน้ำ
  - **วงกลมขีดฆ่า** = ยางลบ
  - **ลูกศรชี้ลง** = เทออกทั้งหมด พื้นจะเปิด ทรายกับน้ำไหลออกด้านล่างจนหมด แล้วพื้นปิดเองภายในประมาณ 8 วินาที (แตะซ้ำ = ปิดพื้นทันที)
- **จอยสติ๊ก (ถ้าต่อไว้):** โยกซ้ายหรือขวา = ลมพัด ทรายและน้ำจะไหลไปทางนั้นมากขึ้น / กดจอย = เทออกทั้งหมด
- จอหรี่และดับตามเวลาใน Settings เหมือนหน้าอื่น ตอนจอดับทรายจะหยุดนิ่ง แตะจอครั้งแรกแค่เปิดจอ ยังไม่โปรย
- ภาพที่โปรยไว้ยังอยู่ถ้าออกแล้วเข้าใหม่ แต่**จะหายเมื่อปิดเครื่องหรือหมุนจอ**

  ✅ เช็ค 1: เข้า Sand ครั้งแรกต้องเห็นกล่อง "Sand & Water" อธิบายวิธีเล่น พอแตะหรือลากบนจอ กล่องต้องหายไป
  ✅ เช็ค 2: ลากนิ้วค้างไว้ ทรายต้องไหลลงมากองเป็นรูปภูเขา / แตะวงกลมสีซ้ำ สีวงกลมต้องเปลี่ยน / แตะหยดน้ำแล้วลาก น้ำต้องไหลแผ่ออกจนเรียบ
  ✅ เช็ค 3: เลือกหินแล้ววาดเส้นเฉียง จากนั้นโปรยทรายลงบนเส้น ทรายต้องค้างอยู่บนเส้นหิน
  ✅ เช็ค 4: แตะลูกศรชี้ลง ทุกอย่างต้องไหลออกทางด้านล่างจนหมด (หินยังอยู่) แล้วเส้นพื้นสีเทาต้องกลับมา

### 3. เกมใหม่: Habit Garden (สวนของฉัน)
ต้นไม้ของคุณ**โตตามกิจกรรมที่บันทึกจริงในหน้า Log** ยิ่งทำครบเป้าบ่อย ต้นไม้ยิ่งใหญ่ ถ้าวันไหนไม่ถึงเป้า ต้นไม้แค่สีซีดลงนิดหน่อย **ไม่ตาย และไม่เล็กลง**
- **โต (Grow):** เป้าที่ทำได้ 1 อัน = +1 (เช่น วันนี้ Water ครบ 8 และ Meal ครบ 3 = +2) ตัวเลขมุมขวาของการ์ด เช่น `17 / 20` = ตอนนี้ได้ 17 ถึง 20 เมื่อไหร่จะโตเป็นขั้นต่อไป
- เป้าแบบ **max** (เช่น Snack ไม่เกิน 2) นับว่าทำได้ ถ้าวันนั้นมีบันทึกอะไรสักอย่าง และ**ไม่เกิน**ลิมิต
- **ดอกไม้** = เป้าที่ทำได้วันนี้ ทำได้กี่อันก็มีดอกไม้กี่ช่อ ขึ้นใหม่ทุกวัน
- **ผลไม้** = วันที่ทำได้**ครบทุกเป้า** ได้ 1 ลูก (บนต้นมีได้สูงสุด 12 ลูก) **แตะผลไม้เพื่อเก็บ** จะขึ้น `+1 fruit` และนับรวมใน `Picked`
- **Streak** (มุมขวาบน) = จำนวนวันติดกันที่ทำได้อย่างน้อยครึ่งหนึ่งของเป้า
- ถ้าวันนี้ทำ**ครบทุกเป้า** จะมี**ผีเสื้อ**บินมาที่สวน
- ท้องฟ้าเปลี่ยนตามเวลาจริง: เช้า (ส้มชมพู) กลางวัน (ฟ้า) เย็น (ม่วงส้ม) กลางคืน (ดาวกับพระจันทร์)
- **ปุ่มเมฆ** (มุมขวาบนของภาพ) = ฝนตกเบา ๆ 5 วินาที ถ้าเป็นเวลากลางวันจะมีรุ้งหลังฝนหยุด
- **เปิดครั้งแรก:** บอร์ดจะอ่านบันทึก 7 วันล่าสุดให้ ต้นไม้จึงไม่ได้เริ่มจากเมล็ดถ้าใช้ SomudTick มาสักพักแล้ว
- บอร์ดนับคะแนนของแต่ละวันตอนเปิด Garden ครั้งแรกของวันถัดไป ถ้าไม่ได้เปิดหลายวัน จะนับย้อนให้สูงสุด 30 วัน
- ถ้าเวลาในบอร์ดยังไม่ตรง (มี `~` หน้านาฬิกา) บอร์ดจะรอก่อน ยังไม่นับวันเก่า กันนับผิดวัน

  ✅ เช็ค 1: เข้า Garden ครั้งแรก ถ้าเคยบันทึกกิจกรรมที่มีเป้ามาหลายวันแล้ว ต้นไม้ต้องไม่ใช่เมล็ด และการ์ดด้านล่างต้องขึ้นชื่อขนาด เช่น `Young plant` กับตัวเลข เช่น `17 / 20`

แฟลชเหมือนเดิม (ดูขั้นที่ 1) ข้อมูลที่บันทึกไว้และไฟล์ในการ์ด SD ไม่หาย

### 1. หน้า Log แบบใหม่ (การ์ด)
- กิจกรรมเป็นการ์ด 2 ใบต่อแถว (จอแนวนอน 3 ใบ) แต่ละใบมีชื่อ ตัวเลขวันนี้ เป้า เวลาที่ทำครั้งล่าสุด และปุ่ม **−** (ยกเลิกครั้งล่าสุด) กับปุ่ม **+1** (บันทึก)
- เส้นเล็กใต้ตัวเลขคือความคืบหน้าไปถึงเป้า เต็มเส้น = ถึงเป้าแล้ว และมีเครื่องหมายถูกที่มุมการ์ด (ถ้าเป็นเป้าแบบ max แล้วเกิน การ์ดจะกลายเป็นสีดำ)
- บรรทัดบนสุด **Goals done 2 / 4** = ทำครบเป้าไปแล้วกี่อันจากทั้งหมด วงกลมทึบ = ครบแล้ว วงกลมโปร่ง = ยังไม่ครบ
- กดค้างที่การ์ด (ไม่ใช่ที่ปุ่ม) = ใส่ตัวเลขเองเหมือนเดิม
  ✅ เช็ค: กด +1 ที่ Water ตัวเลขต้องเพิ่ม 1 และเส้นใต้ตัวเลขต้องยาวขึ้น กด − แล้วต้องลดกลับ แตะที่ชื่อการ์ดแล้วต้องไม่มีอะไรเกิดขึ้น

### 2. หน้า Stats แบบใหม่ (Hours ย้ายมาอยู่ที่นี่)
ด้านบนมี 3 ปุ่ม:
- **All** = ทุกกิจกรรมในหน้าเดียว มีกราฟแท่งเล็ก 7 วัน และเลขวันนี้ แตะแถวไหนก็จะเปิดหน้า Days ของกิจกรรมนั้น
- **Days** = กิจกรรมเดียว 7 วันแบบเดิม (กดลูกศรซ้าย/ขวาเพื่อเปลี่ยนกิจกรรม) จอแนวนอนกล่องตัวเลขอยู่ซ้าย กราฟอยู่ขวา
- **Hours** = ตารางช่วงเวลา (เดิมอยู่ใน Apps) แตะปุ่ม `7 days` เพื่อสลับเป็น 30 วัน
  ✅ เช็ค: Stats → All ต้องเห็นทุกกิจกรรม แตะแถว Water แล้วต้องไปหน้า Days ของ Water / กด Hours ต้องเห็นตารางช่วงเวลา

### 3. Apps เหลือ 4 อัน: Files, AC Remote, Games, Internet
- **Games** = รวมเกม กดเข้าไปแล้วเลือก **Pixel Swim** หรือ **Sudoku** ใต้ชื่อเกมบอกคะแนนสูงสุด หรือบอกว่า Sudoku ค้างไว้ที่ด่านไหน
  ✅ เช็ค: Apps → Games → Sudoku แล้วกด Back ต้องกลับมาที่หน้า Games (ไม่ใช่หน้า Apps)

### 4. Settings แบ่งหมวด
- หน้าแรกมีของที่ใช้บ่อย: ที่อยู่ (Home/Uni), ความสว่าง, เสียง
- ใต้คำว่า **More** เป็นหมวด: **Screen** (เวลาปิดจอ ทิศจอ ธีม สีตัวหนังสือ), **Wi-Fi** (Hotspot, QR, Internet Wi-Fi, Choose Wi-Fi), **Bluetooth**, **Joystick direction**, **Fix touch**, **About** (เวลา แบต การ์ด SD ที่อยู่หน้าเว็บ เวอร์ชัน)
- ด้านขวาของแต่ละหมวดบอกค่าที่ตั้งอยู่ตอนนี้ เช่น `Tall, Light`
  ✅ เช็ค: Settings → Screen → เปลี่ยน Theme เป็น Dark แล้วกด Back ต้องกลับหน้า Settings และบรรทัด Screen ต้องขึ้น `Tall, Dark` / กดแท็บ Settings ด้านล่างตอนอยู่ในหมวด ต้องกลับหน้าแรกของ Settings

### 5. จัดการไฟล์บนบอร์ด (Apps → Files)
- **กดค้าง** ที่ไฟล์หรือโฟลเดอร์ จะมีเมนู **Rename** (เปลี่ยนชื่อ) / **Move** (ย้าย) / **Delete** (ลบ) / Cancel
- **Delete** จะถามก่อนทุกครั้ง แล้วย้ายไฟล์ไป **Trash** (ถังขยะ) ยังกู้คืนได้ ส่วนโฟลเดอร์ลบได้เฉพาะตอนว่าง
- **ถังขยะ:** อยู่ท้ายรายการหน้าแรกของ Files (มีเมื่อมีไฟล์ในถัง) แตะไฟล์ในถังเพื่อ **Put back** (กู้คืนกลับไปโฟลเดอร์เดิม) หรือ **Delete forever** (ลบถาวร) ปุ่ม **Empty** มุมขวาบน = ล้างถังทั้งหมด
- **สร้างโฟลเดอร์:** ปุ่ม **+ รูปโฟลเดอร์** มุมขวาบน แล้วพิมพ์ชื่อด้วยคีย์บอร์ดบนจอ
- **Move:** เลือกโฟลเดอร์ปลายทาง (แตะเพื่อเข้าไปข้างใน ปุ่ม Back = ถอยขึ้น) แล้วกด **Move here**
- ชื่อไฟล์/โฟลเดอร์ใช้ได้เฉพาะ A-Z, 0-9, ช่องว่าง, - และ _ (ยาวไม่เกิน 40 ตัว) ตอนเปลี่ยนชื่อไม่ต้องพิมพ์ .jpg บอร์ดเติมให้
- คลิปมี 2 ไฟล์ (.mjpeg ภาพ + .pcm เสียง) ลบ ย้าย หรือเปลี่ยนชื่อ ไฟล์เสียงจะไปด้วยเสมอ
- **ตอนเปิดดูรูป:** แถบล่างมีปุ่ม `<` (รูปก่อน) / **Back** / **Delete** / `>` (รูปถัดไป) หรือแตะครึ่งซ้าย/ขวาของรูปก็เปลี่ยนรูปได้
- **ดูคลิปจบ:** จะมีปุ่ม **Play again** / **Delete** / **Back**
  ✅ เช็ค 1: Files → กดปุ่ม + โฟลเดอร์ → พิมพ์ `test` → OK ต้องขึ้น "Folder made" และมีโฟลเดอร์ test
  ✅ เช็ค 2: เข้า photos → กดค้างรูป → Move → แตะ test → Move here ต้องขึ้น "Moved" แล้วเข้าไปดูใน test ต้องเจอรูป
  ✅ เช็ค 3: กดค้างรูปนั้น → Delete → Delete ต้องขึ้น "Moved to Trash" แล้วกลับหน้าแรกของ Files ต้องมีแถว Trash → แตะรูปในถัง → Put back รูปต้องกลับไปอยู่ใน test
  ⚠️ ห้ามถอดการ์ด SD ตอนกำลังลบหรือย้ายไฟล์

### 6. จัดการไฟล์จากหน้าเว็บมือถือ (แท็บ รูป/คลิป)
- ด้านบนยังส่งรูป/คลิปได้เหมือนเดิม แต่ตอนนี้ **ส่งเข้าโฟลเดอร์ที่เปิดอยู่** (ถ้าอยู่หน้าแรกของการ์ด รูปจะไป /photos คลิปไป /videos เหมือนเดิม)
- ด้านล่างเป็นรายการไฟล์ แตะชื่อโฟลเดอร์เพื่อเข้าไป แถบบนสุดบอกว่าอยู่โฟลเดอร์ไหน (แตะเพื่อถอยกลับ) มีปุ่ม **⬆ ขึ้น**, **+ โฟลเดอร์ใหม่**, **🗑 ถังขยะ**
- แต่ละไฟล์มีปุ่ม **เปลี่ยนชื่อ / ย้าย / ลบ** ในถังขยะมีปุ่ม **กู้คืน / ลบถาวร** และ **ล้างถังขยะ**
  ✅ เช็ค: สร้างโฟลเดอร์ `trip` จากมือถือ → เปิด trip → ส่งรูป 1 รูป → บนบอร์ด Apps → Files → trip ต้องเจอรูปนั้น

## ของใหม่ใน v6

แฟลชเหมือนเดิม (ดูขั้นที่ 1) ข้อมูลที่บันทึกไว้ไม่หาย

1. **Water นับเป็นครั้งแล้ว** กด + หนึ่งทีได้ +1 ครั้ง เป้าเริ่มต้น 8 ครั้งต่อวัน ข้อมูลเก่าที่เคยเก็บเป็น ml จะเปลี่ยนเป็นจำนวนครั้งให้เอง
   ✅ เช็ค: หน้า Log แถว Water ขึ้นเลขแบบ `4 /8` กด + แล้วต้องเพิ่มทีละ 1 (ไม่ใช่ 250)
2. **ราคาน้ำมัน (Apps → Internet → News)** เลขรุ่นน้ำมันย้ายขึ้นหน้าชื่อเป็นตัวหนา เช่น **95** แก๊สโซฮอล์, **E20** แก๊สโซฮอล์, **B20** ดีเซล ตัดคำว่า S EVO ออกเพราะมีทุกแถวอยู่แล้ว ชื่ออยู่ซ้าย ราคาวันนี้อยู่ตรงกลาง ขวาสุดคือราคาพรุ่งนี้ **▲ แดง = แพงขึ้น, ▼ เขียว = ถูกลง, same = เท่าเดิม**
   ✅ เช็ค: จอแนวตั้งต้องเห็นเลขรุ่น ราคา และลูกศรครบทุกแถว หัวกล่อง "Oil price" กับ "Bangchak" ต้องไม่ทับกัน (ถ้าวันนั้นราคาไม่เปลี่ยนเลย ทุกแถวจะขึ้น same ไม่มีสีเป็นเรื่องปกติ)
3. **แก้บั๊กอากาศเลื่อนแล้วทับหัวจอ** (สาเหตุคือไลบรารีจอลบกรอบตัดภาพตอนวาดไอคอนฝน) ตอนนี้ชื่อ Khon Kaen อยู่เหนืออุณหภูมิ และพยากรณ์ 3 วันใช้ชื่อวัน (Today, Sat, Sun) ไม่ทับไอคอนแล้ว
   ✅ เช็ค: เข้า Weather แล้วเลื่อนลงสุด ตัวหนังสือต้องไม่ขึ้นไปทับปุ่ม Weather/News/Reload
4. **Sudoku เล่นด้วยจอยได้** ดันจอย = ย้ายกรอบสีฟ้า / กดจอย = เปิดแป้นตัวเลข / ดันเลือกเลข / กดจอยอีกที = ใส่เลข ในเมนู New game ก็ดันขึ้นลงแล้วกดเลือกได้ แตะจอยังเล่นได้เหมือนเดิม ถ้าหมุนจอเป็นแนวนอน กระดานจะใหญ่เต็มความสูง ปุ่มย้ายไปอยู่ขวา
   ✅ เช็ค: เข้า Sudoku แล้วดันจอยขวา กรอบฟ้าต้องขยับไปทางขวาทีละช่อง ถ้าดันค้าง กรอบต้องเลื่อนต่อไปเรื่อย ๆ
   ❌ ถ้าจอยไม่ทำงานใน Sudoku แต่เกมใช้ได้ ให้ออกแล้วเข้าใหม่โดย**ปล่อยจอยไว้ตรงกลาง** (ตอนเปิดแอป บอร์ดเช็คว่ามีจอยต่ออยู่ไหม) ถ้าทิศผิด ให้ทำ Settings → Joystick direction ใหม่
5. **ไอคอน Sudoku** ตัวเลขอยู่ในช่องพอดีแล้ว
   ✅ เช็ค: หน้า Apps ไอคอน Sudoku เป็นตาราง 3×3 มีเลข 5, 3, 8 อยู่ในช่อง
6. **เอา Pocket lock ออกแล้ว** แตะจอก็ปลุกจอได้เลย และเพิ่ม **Screen off after** (ปิดจอเมื่อไม่ได้แตะ) เลือกได้ 30s / 1m / 5m / Never (ไม่ปิดเลย) จอจะหรี่ลงก่อนดับเล็กน้อย
   ✅ เช็ค: Settings → เลือก 30s → วางไว้เฉย ๆ ประมาณ 20 วินาทีจอต้องหรี่ แล้วครบ 30 วินาทีจอต้องดับ แตะจอแล้วจอต้องติด
   ⚠️ เลือก Never แบตจะหมดเร็วมาก
7. **Pixel Swim แบบใหม่** ไม่มีหางแล้ว กินจุดที่เรืองแสงแล้วตัวจะใหญ่ขึ้น พอใหญ่ถึงขนาดหนึ่งจะขึ้นด่านใหม่ (Level) แล้วตัวกลับมาเล็ก เม็ดพิกเซลน้ำพื้นหลังเพิ่มจาก 520 เป็น 1400 เม็ด
   ✅ เช็ค: กินจุด 1 เม็ด ตัวต้องโตขึ้นนิดหนึ่ง และคะแนน Score ต้องขึ้น +1
8. **แยก Wi-Fi เป็น 2 สวิตช์** ใน Settings:
   - **Phone link → Hotspot SomudTick: ON/OFF** = บอร์ดปล่อย Wi-Fi ของตัวเองให้มือถือเข้าหน้าเว็บ
   - **Internet → Internet Wi-Fi: ON/OFF** = บอร์ดไปเกาะ Wi-Fi บ้าน/ฮอตสปอตมือถือเพื่อใช้เน็ต (ตั้งเวลา อากาศ ข่าว) ใต้ปุ่มจะบอกว่า Connected กับ Wi-Fi ไหน ปุ่ม **Choose Wi-Fi** ใช้เลือก Wi-Fi
   ✅ เช็ค: ปิด Hotspot แล้วในมือถือต้องไม่เห็น Wi-Fi ชื่อ SomudTick (รอประมาณ 10 วินาที) แต่หน้า Internet บนบอร์ดยังโหลดข่าวได้ / ปิด Internet Wi-Fi แล้วจุดขาวบนแถบหัวต้องหายไป
   💡 ถ้าปิด Hotspot แต่บอร์ดต่อ Wi-Fi บ้านอยู่ มือถือที่อยู่ Wi-Fi บ้านเดียวกันยังเปิดหน้าเว็บได้ โดยสแกน QR ในหน้า Settings
9. **เช็คตัวหนังสือทุกหน้าแล้ว** ทั้งแนวตั้งและแนวนอน (Settings, Stats, Apps, AC, Keyboard, Bluetooth, Wi-Fi, Sudoku, Game) ตัวหนังสือที่เคยล้นหรือทับกันถูกย่อหรือเปลี่ยนเป็นคำสั้นลง เช่น Stats ใช้ Today / Week / Avg / Total แท็บล่างกว้างตามความยาวคำ คำว่า Settings จึงไม่ล้นแล้ว
   ✅ เช็ค: เปิดทุกหน้าแล้วดูว่าไม่มีตัวหนังสือทับกัน ถ้ายังเจอ ถ่ายรูปส่งมาได้เลย

## ของใหม่ใน v5 (ลองตามนี้หลังแฟลช)

1. ตั้งทิศจอยสติ๊ก: Settings → Joystick direction แล้วทำตามที่จอบอก คือปล่อยจอย → ดันขึ้นค้างไว้ → ปล่อย → ดันขวาค้างไว้
   ✅ เช็ค: จอขึ้น "Done!" จากนั้นเข้า Game แล้วดันขึ้น ลูกบอลต้องขึ้น ดันขวา ลูกบอลต้องไปขวา
2. หน้า Wi-Fi: Settings → Choose Wi-Fi (v5 ชื่อ Wi-Fi networks) บอร์ดจะค้นหา Wi-Fi รอบตัวเอง แตะชื่อ Wi-Fi แล้วพิมพ์รหัสบนคีย์บอร์ดของจอ แล้วกด OK (ปุ่ม 123 = ตัวเลข/สัญลักษณ์, ABC = ตัวพิมพ์ใหญ่, แตะช่องรหัส = โชว์/ซ่อนรหัส)
   ✅ เช็ค: กล่องด้านบนขึ้น "Connected: ชื่อ Wi-Fi" และแถบหัวมีจุดขาวทึบ
3. หน้า Bluetooth: Settings → Bluetooth devices → Scan บอร์ดจะหาอุปกรณ์ BLE รอบตัวเป็นเวลา 5 วินาที (เช่น นาฬิกา มือถือ หูฟัง) บอร์ดนี้**ต่อลำโพงหรือหูฟังเพื่อเล่นเพลงไม่ได้** เพราะชิปมีแค่ BLE
   ✅ เช็ค: เปิด Bluetooth มือถือไว้ แล้วต้องเห็นรายการอย่างน้อย 1 อัน
4. Internet: แก้ปัญหาอากาศโหลดไม่ขึ้นแล้ว แท็บ News ด้านบนเป็นราคาน้ำมันวันนี้และพรุ่งนี้ (บางจาก) ด้านล่างเป็นข่าวไอทีจาก Blognone ปุ่มขวาสุดเปลี่ยนชื่อเป็น **Reload** แปลว่าโหลดข้อมูลใหม่
   ✅ เช็ค: แท็บ Weather ต้องขึ้นอุณหภูมิกับ PM2.5 ส่วนแท็บ News ต้องขึ้นกล่อง "Oil price" ก่อนรายการข่าว
5. ส่งรูป/คลิปจากมือถือเข้าบอร์ด: ต่อมือถือกับ Wi-Fi ของบอร์ด แล้วเปิดหน้าเว็บ เข้าแท็บ **รูป/คลิป** กด "เลือกรูป" หรือ "เลือกคลิป" มือถือจะย่อรูปหรือแปลงคลิปเอง แล้วส่งลงการ์ด SD ในบอร์ด (ต้องเสียบการ์ดไว้)
   ✅ เช็ค: ข้อความขึ้น "ส่งเสร็จแล้ว" และรายการในการ์ดด้านล่างมีไฟล์ใหม่ จากนั้นเปิดที่บอร์ด Apps → Files → photos หรือ videos ต้องเจอไฟล์

## ขั้นที่ 1: แฟลช firmware ใหม่
**อัปเดต (บอร์ดมีโปรแกรม SomudTick อยู่แล้ว):** ใช้ `SomudTick_app.bin` ที่ `0x10000` ตามขั้นตอนใน "ของใหม่ใน v11.5" ข้อ 0 การตั้งค่าและบันทึกไม่หาย

**ลงบอร์ดใหม่ครั้งแรก (บอร์ดเปล่า):**
1. เปิด https://espressif.github.io/esptool-js/ ใน Chrome หรือ Edge ตั้ง Baudrate เป็น 115200 แล้วกด **Connect**
   ✅ **เช็ค:** กล่องดำขึ้น `Chip is ESP32-S3`
2. ตั้ง Flash Address เป็น **`0x0`** เลือกไฟล์ `SomudTick_merged.bin` แล้วกด **Program**
   ✅ **เช็ค:** ขึ้น `Hash of data verified`
3. ถอดสาย USB แล้วปิด/เปิดสวิตช์ (ปุ่ม RESET อยู่ในกล่อง)
   ✅ **เช็ค:** จอขึ้นคำว่า "SomudTick / Starting..." แล้วขึ้นหน้าปรับทัช (Touch setup) เพราะการตั้งค่าเริ่มใหม่ทั้งหมด
> บอร์ดที่มี SomudTick อยู่แล้วต้องสั่งให้เข้าโหมดแฟลชก่อน: Settings → About → Update firmware → Restart

> ถ้าเคยตั้งชื่อกิจกรรมเองเป็นภาษาไทย ชื่อนั้นจะยังเป็นภาษาไทยเหมือนเดิม ถ้าอยากเปลี่ยนเป็นอังกฤษ ให้แก้ในหน้าเว็บ แท็บ "กิจกรรม"

## ขั้นที่ 2: ต่อสาย (ดูรูป `wiring.png` ประกอบ)
⚠️ **ถอดสาย USB และแบตออกก่อนต่อสายทุกครั้ง**

| อุปกรณ์ | ขาอุปกรณ์ | ต่อเข้าบอร์ด (ช่องไหน) |
|---|---|---|
| จอยสติ๊ก | VRX | **IO2** (ช่อง Expansion Pins) |
| จอยสติ๊ก | VRY | **IO3** (ช่อง Expansion Pins) |
| จอยสติ๊ก | SW | **IO14** (ช่อง Expansion Pins) |
| จอยสติ๊ก | +5V | **3.3V** (ช่อง I2C) ⚠️ ห้ามต่อ 5V |
| จอยสติ๊ก | GND | **GND** (ช่อง I2C) |
| KY-005 | S | **IO21** (ช่อง Expansion Pins) |
| KY-005 | ขากลาง | **3.3V** (ช่อง I2C) |
| KY-005 | - | **GND** (ช่อง I2C) |
| DS3231 (v11.2) | SDA / SCL | **IO16 / IO15** (ช่อง I2C) |
| DS3231 (v11.2) | VCC / GND | **3.3V / GND** (ช่อง I2C) ⚠️ ห้ามต่อ 5V |

- ช่อง I2C มีขา 3.3V และ GND แค่อย่างละ 1 ขา แต่ต้องต่อ 2 อุปกรณ์ (3 อุปกรณ์ถ้ามี DS3231) ให้แยกสาย เช่น ใช้บอร์ดทดลอง (breadboard) หรือบัดกรีสายรวมกัน
- หัวเสียบบนบอร์ดเป็นแบบ JST ตัวเล็ก ให้ใช้สายที่แถมมากับบอร์ด

✅ **เช็คก่อนเสียบไฟ:** ไล่นิ้วตามสายทีละเส้นเทียบกับตาราง โดยเฉพาะ**สายแดงของจอยต้องไปที่ 3.3V** ไม่ใช่ 5V (ช่อง UART มีขา 5V อยู่ อย่าต่อผิดช่อง)

## ขั้นที่ 4: สั่งแอร์ (AC Remote)
Apps → **AC Remote** หันหลอด KY-005 ไปที่แอร์ ห่างไม่เกิน 1–3 เมตร
1. ตั้ง Mode เป็น **Cool** ตั้งอุณหภูมิ แล้วกดปุ่มใหญ่ **OFF (tap to turn on)**
   ✅ **เช็ค:** มุมขวาบนขึ้นคำว่า `Sent!` ไฟ LED หลังบอร์ดกะพริบฟ้า และ**แอร์ต้องมีเสียงปี๊บ**แล้วเปิดขึ้นมา
2. ถ้าแอร์ไม่มีเสียงปี๊บ แปลว่าใช้รุ่นรหัสผิด ให้กดปุ่ม **Type** (DKE → JKE → NKE → LKE → CKP → RKR) ทีละครั้ง แล้วกด ON ใหม่ ทำไปจนแอร์ปี๊บ
   ✅ **เช็ค:** พอเจอ Type ที่ใช้ได้ ลองกด + / − แล้วแอร์ต้องปี๊บทุกครั้ง บอร์ดจำ Type นั้นไว้ให้
3. **เช็คว่าหลอด IR ยิงแสงจริงไหม:** เปิดกล้องมือถือ (ใช้กล้องหน้าจะเห็นชัดกว่า) ส่องไปที่หลอด KY-005 แล้วกดปุ่มใดก็ได้บนบอร์ด ต้องเห็นแสงสีม่วงจาง ๆ กะพริบในกล้อง
   ❌ ถ้าไม่เห็นแสงเลย ให้เช็คสาย S → IO21 และ - → GND

ความหมายปุ่ม: **Mode** = โหมด (Auto อัตโนมัติ, Cool ทำความเย็น, Dry ลดความชื้น, Fan พัดลมอย่างเดียว) / **Fan speed** = ความแรงพัดลม (Auto หรือ 1–5) / **Swing** = บานสวิงขึ้นลง (Auto = ส่ายไปมา, 1 = บนสุด … 5 = ล่างสุด) / **Quiet** = โหมดเงียบ

⚠️ บอร์ดไม่รู้ว่าแอร์เปิดหรือปิดอยู่จริง ถ้าไปกดรีโมทจริงในระหว่างนั้น ปุ่ม ON/OFF บนบอร์ดอาจแสดงสถานะไม่ตรงกับแอร์ ให้กดใหม่อีกครั้ง

## ขั้นที่ 5: ดูรูปและคลิปจาก SD (Files)

### 5.1 ติดตั้ง ffmpeg (ทำครั้งเดียว)
เปิด **PowerShell** (กดปุ่ม Windows แล้วพิมพ์ PowerShell) แล้วพิมพ์
```
winget install Gyan.FFmpeg
```
✅ **เช็ค:** ปิดแล้วเปิด PowerShell ใหม่ พิมพ์ `ffmpeg -version` ต้องขึ้นบรรทัดที่ขึ้นต้นด้วย `ffmpeg version ...`

### 5.2 แปลงไฟล์
ลากไฟล์รูปหรือคลิป (ลากทีละหลายไฟล์ได้) ไปวางบนไฟล์ `convert_for_SomudTick.bat`
✅ **เช็ค:** หน้าต่างดำขึ้น `OK` ทุกไฟล์ แล้วโฟลเดอร์ `SD_card` เปิดขึ้นมาเอง ข้างในมี
- `photos\ชื่อรูป.jpg`
- `videos\ชื่อคลิป.mjpeg` คู่กับ `videos\ชื่อคลิป.pcm` (ไฟล์ .pcm คือเสียง ต้องอยู่คู่กันเสมอ)

> ตัวแปลงจะย่อรูปและคลิปให้พอดีกับจอ และตั้งคลิปเป็น 15 ภาพต่อวินาที ไฟล์ .mjpeg จึงใหญ่กว่า mp4 ประมาณ 5–10 เท่า คลิป 1 นาทีใช้ที่ประมาณ 5–8 MB
> **รูปจาก iPhone (.HEIC):** ถ้าขึ้น FAILED ให้ตั้งกล้อง iPhone ที่ Settings → Camera → Formats → **Most Compatible** แล้วถ่ายใหม่ หรือส่งรูปเข้าคอมผ่าน LINE หรืออีเมล ซึ่งจะแปลงเป็น JPG ให้เอง

### 5.3 ก๊อปลงการ์ด
ใช้การ์ด microSD ไม่เกิน 32GB ฟอร์แมตเป็น **FAT32** แล้วก๊อปโฟลเดอร์ `photos` และ `videos` ลงการ์ด แล้วเสียบการ์ดเข้าบอร์ด
✅ **เช็ค:** Apps → **Files** ต้องเห็นโฟลเดอร์ photos กับ videos (ถ้าขึ้น "No SD card found" ให้เสียบการ์ดใหม่ให้แน่น แล้วแตะที่ข้อความเพื่อลองอีกครั้ง)

### 5.4 วิธีดู
- **รูป:** แตะชื่อรูปเพื่อเปิด แตะ **ด้านขวาของจอ = รูปถัดไป**, **ด้านซ้าย = รูปก่อนหน้า**, **ตรงกลาง = กลับ**
- **คลิป:** แตะชื่อคลิปเพื่อเล่น จอจะหมุนตามแนวคลิปเอง **แตะตรงไหนก็ได้ = หยุด**
  ✅ **เช็ค:** มีเสียงออกลำโพง (ต้องเสียบลำโพงที่ช่อง SPEAKER ก่อน) ถ้าไม่มีเสียง ให้เข้า Settings → Sound volume กด + แล้วลองใหม่
- ปุ่ม **Back** มุมซ้ายบน = กลับไปโฟลเดอร์ก่อนหน้า

- **Log:** ปุ่ม + = บันทึก / ปุ่ม − = ยกเลิก (ของเมื่อคืนก็ได้ ถ้าไม่เกิน 6 ชั่วโมง) / กดค้างที่การ์ด = ใส่ตัวเลขเอง / ปัดขึ้นลงเพื่อเลื่อน / ปุ่ม **Stats** มุมขวาบน = เปิดหน้าสถิติ / **กดค้าง**ป้าย Home–Uni บนแถบหัว = สลับสถานที่
- **ปุ่ม BOOT** (อยู่ในกล่อง ปกติกดไม่ได้): กดสั้นตอนอยู่หน้า Log = บันทึกกิจกรรมแรกในรายการ / หน้าอื่น = ปลุกจอ / กดค้าง 3 วินาที = ปรับทัชใหม่ ถ้าทัชเพี้ยนจนกดไม่ได้ ให้ใช้จอยไปที่ Settings → **Fix touch (calibrate)** แทน
- **Settings:** หน้าแรก = ที่อยู่ ความสว่าง เสียง / หมวด Screen = เวลาปิดจอ ทิศจอ ธีม สีตัวหนังสือ / หมวด Wi-Fi = Hotspot, QR code, Internet Wi-Fi / Bluetooth / Joystick direction / Fix touch / About

## สำหรับคอมไพล์เองใน Arduino IDE
**v10 เปลี่ยนการตั้งค่า 2 ข้อ:** ESP32S3 Dev Module, Flash 16MB, **OPI PSRAM**, Partition Scheme: **Huge APP** (โปรแกรมจะใช้ไฟล์ `partitions.csv` ในโฟลเดอร์แทนให้เอง ซึ่งเหมือน Huge APP ทุกอย่างและเพิ่มพื้นที่ logs 12 MB), **USB Mode: USB-OTG (TinyUSB)** (เดิม Hardware CDC and JTAG), **USB CDC On Boot: Disabled** (เดิม Enabled) ⚠️ ห้ามลบไฟล์ `partitions.csv` และห้ามเลือก Partition Scheme อื่น ไม่อย่างนั้นบันทึกจะหาย แล้วลงไลบรารีเพิ่มอีก 1 ตัว คือ **IRremoteESP8266 เวอร์ชัน 2.9.0 ขึ้นไป** ถ้าใน Library Manager มีแต่เวอร์ชันที่เก่ากว่านี้ ให้โหลด ZIP จาก https://github.com/crankyoldgit/IRremoteESP8266 แล้วติดตั้งผ่านเมนู Sketch → Include Library → Add .ZIP Library
✅ **เช็ค:** กด Verify แล้วต้องขึ้น `Sketch uses ... (59%)`

v11.6 ทดสอบคอมไพล์กับ esp32 by Espressif **3.3.12**, LovyanGFX 1.2.30, ArduinoJson 7.4.3 และ IRremoteESP8266 2.9.0 ได้ `Sketch uses 2046699 bytes (65%)`
(arduino-cli: `-b esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi,PartitionScheme=huge_app,USBMode=default,CDCOnBoot=default`)
> ไฟล์อัปเดต `SomudTick_app.bin` คือไฟล์ `SomudTick.ino.bin` ที่ arduino-cli ทำให้ (แฟลชที่ `0x10000`) ส่วน `tools/build_firmware.sh` ทำทั้งสองไฟล์ให้
> ถ้าทำ `SomudTick_merged.bin` เองจาก arduino-cli **อย่าใช้ไฟล์ `.merged.bin` ขนาด 16 MB ที่โปรแกรมทำให้** เพราะไฟล์นั้นเขียนทับทั้ง Flash รวมถึงข้อมูลที่บันทึกไว้ ให้รวมเฉพาะส่วนโปรแกรมด้วยคำสั่ง (ไฟล์นี้ยังทับการตั้งค่า ใช้ลงบอร์ดใหม่เท่านั้น)
> `esptool --chip esp32s3 merge-bin -o SomudTick_merged.bin --flash-mode dio --flash-freq 80m --flash-size 16MB 0x0 SomudTick.ino.bootloader.bin 0x8000 SomudTick.ino.partitions.bin 0xe000 boot_app0.bin 0x10000 SomudTick.ino.bin`
